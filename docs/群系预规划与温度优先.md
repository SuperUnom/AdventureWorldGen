# 群系预规划与温度优先

2026-09-09 的规划调整作用于新生成的计划。结构附带群系与显式必要群系共同进入需求展开、模板容量预留和竞争生长。

## 地形预规划

在最终地形、水文和侵蚀生成之前，用区域内部的可用面积匹配群系允许的具体模板和高度包络。结构提供多个候选群系时，先检查每个候选的总容量，选择可行候选，不再固定取第一个。候选区域优先接近 `大陆半径 × 冒险等级 / 10`，同时考虑可用面积和天然模板适配程度。

先为所有必要需求预留最低面积，再用剩余容量争取目标面积的 125%，给后续温湿度筛选和水文留出余量。目标预留不足时接受已有容量；无法满足最低容量时仍报告具体缺口。模板面积通过分配更多或更少的区域容量自适应调整，不在群系生长后重塑地形。

## 种子与扩张

出生群系和出生结构承载区优先固定。其余必要群系按冻结地形中实际合法面积升序播种；面积通过 16 格候选目录估算，多候选群系使用合法土地并集，避免重复计数。相同供给时先放目标面积大的需求，再按冒险等级与稳定 ID 排序。恶地等依赖少量特定模板的群系因此先于常见地形群系寻找种子。

种子搜索为每档温度距离保留最多 1024 个贪心候选，优先匹配配置中的温度，再考虑相邻温度和更远温度。同档内比较气候适宜度、冒险等级、拥挤程度和局部容量，并用确定性扰动打破近似平局。严格的连通空间预检找不到位置时，将探测要求从最多 4096 格降低至最多 256 格，并支持 16 → 8 → 4 格搜索细化；最终最低面积仍必须满足。

必要群系和填充群系的生长队列都先比较温度距离。高差不再计入扩张路径成本；湿度、距离和边缘邻居支持度参与次级选择。禁止模板和硬高度限制仍决定格子是否可用；r31 起河流允许前沿跨越，但水下格不参与面积。必要群系最低面积未满足时，只重新选择失败群系的位置，最多三轮，不改写已确定的环境。

## 配置与冻结字段

`very_cold` 不再绑定原生覆雪能力，可与 `cold` 等类型共同配置。默认非常冷群系仍由默认 JSON 决定；规划不再按原版海拔雪线排除自定义配置。湿度供应按可行地形模板计算；r31 起河流不再强制提高用于群系分配的湿度。

温度和湿度在确定后以惰性分块缓存保存精确 4 格中心值；连续非网格查询保留原坐标精度。地形索引共享格中心样本，并缓存整数位置样本、等级接受结果、等级代价和模板容量；成本图缓存每个精确坐标的细化难度结果。回退只改变选点标准，不重新生成地形、高度或温湿度场。

实现缓存标识更新为 `planner-v2-impl-2026-09-09-capacity-components-v2`，公开格式仍为 `plan-v2`。新旧算法的布局不保证相同，检验新规则应使用新建世界。

## 种子 7993：重复连通空间搜索修复

用户提供的 `crash-2026-09-09_00.49.27-server.txt` 显示：旧 `adventureworldgen-0.1.0-r25.jar` 在雪林种子的 `selectSeed → capacity → legal` 路径耗尽 12000000 次预算。已核对实例 JAR 与上一轮新构建的类摘要不同，但两者默认 JSON 配置相同。

修复针对重复工作本身：

- 每次种子选择为每个候选群系建立独立的连通空间探测缓存，绑定当前不变的占用状态。失败连通区域完整遍历后，把准确面积记到其全部格子，后续候选、温度回退及 16/8/4 格搜索直接复用。已判定的阻塞边界也不重复访问。
- 真实最低面积已被证明不可满足的区域，在降低探测标准后仍跳过，避免选中必败种子再反复重试。
- 较大可用区域仍在达到探测目标后提前停止；重新播种涉及占用变化时建立新缓存，不复用过期连通结果。
- 地形、湿度和预留区合法性统一按“群系 + 格子”缓存。12000000 次保护计数只记录首次合法性判定，缓存命中不重复消耗预算。未提高预算上限，也未放宽真实最低面积或地形约束。

专项回归用一个 3072 格的不足面积区域，逐一测试全部 3072 个候选种子，总查询数小于 3500；同时覆盖独立可行区域、大区域提前停止、降低探测标准不能绕过已知缺口，以及占用变化后重新探测。

测试同步移除与本轮配置约定冲突的“冷带必须无原生降雪”断言，改为逐格校验冻结湿度和岸线规则；温度偏好与相邻带回退由 `GreedyBiomePlanningTest` 独立验证。必要群系最低有效面积、连通性、模板合法性、结构生成和存档重载断言均保留。
