# r14：自然群系、方块级过渡与软冒险等级

对应用户反馈的五项修改均已实现，产物为 `neoforge/build/libs/adventureworldgen-0.1.0-r14.jar`。

## 方块级过渡

旧地表直接使用取整后的 4×4 群系结果，沙土等材质因此沿大阶梯切换。现在从相邻承载群系插值，叠加小幅连续扭曲与基础尺度为 3 方块的相关噪声；只在局部交界选择两个主要邻居，群系内部保留主体。

`AdventureChunkGenerator.buildSurface` 的陆地步骤逐方块调用 `surfaceBiomeAt`，同一 4×4 范围可生成两侧的不同材料。实际群系采样也使用这个混合场，植被继续由原版特征读取混合后的群系数据生成。河流、湖泊与海洋覆盖保持独立。

原版区块的群系存储仍为 4×4×4 调色板；这里实现的是**逐方块地表材料混合，以及配合它的群系采样过渡**，没有声称修改了原版存储精度。草叶颜色仍由原版群系颜色采样与客户端混合设置处理。

## 必须群系的形状与面积

- 初始空间评分从单纯的圆心距离改为连续坐标扭曲、方向拉伸、大尺度起伏和地形高差的组合。
- 仍从锚点沿合法四邻接前沿生长，避免跨越禁区开出碎岛。锚点评分加入地形边缘与拥挤的软惩罚，给大群系留出扩展空间。
- 默认 27 个必须群系的面积区间从 `[16384,32768]` 改为 `[65536,131072]`，上下限均扩大 4 倍。当前先满足最低面积，保留所有面积与地形硬约束。
- 结构承载区域仍保持与冻结足迹及保护范围相符的独立掩码。必须条目和结构承载条目不混为同一面积要求。

承载掩码用于面积与结构验证；边缘显示混合、水体覆盖会使屏幕上某个群系 ID 的面积与承载配额略有差异。

## 冒险等级改为软偏好

目标等级仍是 `0～10`。实际偏好值为 `A = 10 × 旅行成本 / 海岸参考成本`，使用完整成本图上的 16 方块候选成本。设 `d = A − 目标等级`：

```text
P = 0.05 × d² + max(0, |d| − 0.35)² × (d < 0 ? 1.6 : 1.0)
```

候选评分使用 `4 × P`，再加温度、拥挤、附近地形兼容和确定性随机微扰。高等级内容过早出现的惩罚更重，但偏离始终有限、连续；不会因为不落在旧等级区间而拒绝候选。无法得到可达成本的位置使用偏高的有限回退值，保持软约束语义。

群系锚点与结构候选都按此偏好排序。出生结构可以配置非零等级，出生位置优先，原等级目标保留。配置仍检查等级的数值类型与 `0～10` 范围，以及身份、数量、面积、地形、足迹和出生安全等硬条件。

等级偏好不会保证每两个同级或相邻等级条目的成本严格排序；地形、温度与空间竞争可以导致局部交叉。它也不改变原版怪物强度。

## 填充布局与默认配置

默认填充池由 8 种扩大到 29 种，覆盖平原、不同树林、丛林、湿地、草甸、樱花及多种山地。种子间距从 512 缩至 256 方块，使填充区域与放大后的必须地块更接近。

初始化先匹配源位置的合法地形。后续标签交换同时考虑温差、相邻同 ID 连成大片的惩罚，以及由已规划锚点与向外距离共同引导的等级偏好。填充 ID 的等级参考同 ID 必须条目的平均目标，或出生/结构承载目标；没有对应目标的 ID 不附加等级偏好。

交换保留初始化后的各 ID 源数量，温度与等级都是软目标。源数量不等于实际面积，也不保证某个填充 ID 必定出现；需要出现保证的内容仍列入 `required`。原有 `temperature_*` 诊断字段在此版本记录的是包含这些项的布局总目标，不应解读为纯温差代价。

较窄的模板过渡允许预留更多真实区域内部容量，宏观预留安全间隔由 384 调为 144；最终成功仍以实际合法单元分配和完整验证为准，没有取消面积检查。
