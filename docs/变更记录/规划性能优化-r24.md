# r24：首次规划性能优化

此次优化针对新世界首次规划，地形仍为 `terrain-r22`。保留规划配置、采样间距、侵蚀次数、群系面积规则、搜索顺序和计划缓存标识；已有 READY 计划可以直接加载。

## 已确认的开销与修复

- 海岸距离：JFR 显示最近线段搜索频繁创建优先队列及队列节点。改为按包围盒距离优先访问近侧子树；严格保留等距时较小线段编号胜出的规则。
- 区域地形：选择最近区域与计算混合权重原本重复查询相同邻域。复用一次 5×5 邻域的精确距离，并保留超出可证明范围时的原搜索回退。每线程只缓存一个不可变区域窗口，减少连续采样中的键对象和并发表查询。
- 山脉影响：同一地形贡献的山脉包络原本计算两次，现复用一次结果；投影距离任一分量超出支撑半径时，其贡献确定为零，省去距离开方。
- 群系分配：打包坐标放入 `HashMap<Long, …>` 和 `HashSet<Long>` 时，`Long.hashCode()` 将高低位异或，规则网格中大量坐标碰撞。采用 Minecraft 已提供的 fastutil 8.5.12 数值键集合，改善散列并减少装箱；兼容性缓存以字节区分未查询、允许和禁止。输出掩码仍按原顺序排序，生长前沿和竞争调度的比较规则保持不变。
- 成本图：固定 65,536 槽缓存复用整数端点和中点的完整地形样本。对角线小数坐标及边界交点保持原坐标计算，不插值替代原采样；缓存开销计入成本图内存预算。

这些缓存只保存已有确定性函数的结果，不写入计划，不影响随机数或终止条件。

## 可复现验证

完整 `test build --offline` 通过，共 130 项单元测试。新增海岸最近点与全线段穷举对照（含精确等距）、区域缓存跨线程及窗口替换检查、成本图与无采样缓存参考图的整数/小数坐标对照。现有群系面积、结构承载、侵蚀、配方、存档与确定性测试也全部通过。

独立基准使用默认半径 3000、种子 7331、`-Xmx2g` 和 JFR profile，走 `RuntimePlanner` 的完整流程，包括侵蚀、河流、成本图、群系分配、有效面积校验和原子存盘。结构使用固定测试方块盒，因此该基准不包含真实金字塔 NBT 准备；游戏测试另外覆盖原版结构适配器。

最终对照在单元测试结束后依次运行两个独立 JVM，没有并行执行其他测试：

| 阶段 | 优化前 | r24 |
|---|---:|---:|
| 河流规划 | 69.47 秒 | 34.31 秒 |
| 成本图 | 41.19 秒 | 19.24 秒 |
| 群系分配 | 61.96 秒 | 26.68 秒 |
| 填充与过渡 | 33.39 秒 | 14.82 秒 |
| 全流程（含其余阶段、校验、存盘） | **250.38 秒** | **127.62 秒** |

完整规划耗时减少 **49.03%**，约加速 **1.96 倍**。此前探索轮次测得旧版 227.25 秒、第一轮优化 147.10 秒；最终表格采用上述独立复测结果。侵蚀模拟仍保留原工作量，未通过减少模拟次数换取提速。

四次规划解压后的完整计划字节完全一致，SHA-256 均为 `43a7aa528a6c62a4e159c829cf00ca31d71c7646d307ae3fe55481af6f78344c`。每次均为 145,161 个成本节点、174,476 条规范边、548,308 次精确群系地形采样和 2,693,079 次生长/搜索操作。报告位于 `neoforge/build/reports/planning-r24/`，包括前后分阶段计时、日志和 `benchmark.json`。

游戏内定向回归 **1/1 通过**：默认配置首次规划（包含真实原版金字塔适配器）耗时 **129.70 秒**，随后通过群系地形约束校验和 READY 计划直读/群系一致性检查。整个测试用例耗时约 2.258 分钟，另有测试服务器停止与保存区块的时间；这些额外时间不计入上述规划耗时。

在 `neoforge` 目录生成 classpath 后执行；输出目录必须不存在，工具拒绝用 READY 缓存冒充新规划：

```sh
./gradlew -I tools/planning-benchmark.gradle writePlanningBenchmarkClasspath --offline
java -Xmx2g -cp "$(cat build/planning-benchmark-classpath.txt)" \
  tools/PlanningBenchmark.java \
  src/main/resources/data/adventureworldgen/adventureworldgen/profiles/default.json \
  build/planning-benchmark-new-world 7331
```

游戏内完整默认配置规划、真实结构准备、群系约束和 READY 重载验证：

```sh
./gradlew runGameTestServer -I tools/r24-gametest.gradle \
  -PterrainAuditWorld=run-r24-planning-new --offline
```

本机验证时遇到系统 inotify 实例上限，因此只在独立测试目录的 `config/fml.toml` 中设置 `disableConfigWatcher = true`，关闭配置文件热监听后运行；配置加载和规划本身照常执行。生产模组默认设置未修改。

测试伴生模组和基准工具不进入生产 JAR。性能会随 CPU、世界配置和种子变化，基准倍率不能直接作为每台机器的等待时间承诺。
