# r19 河流形态与河床

本次水文版本为 `ftf-hydrology-adapted-v2`。不兼容旧版河流计划，请新建世界验收。

- 河源分散到大陆内陆的不同位置，出口方向相对河源径向偏转，避免围绕中心放射。长内陆流域不足时继续搜索较短的沿海流域，避免地形预留或侵蚀后无法补齐河网。
- 河道从河口/汇入口向上游逐步生长。每一步结合随机角加速度、转弯惯性、目标方向和附近地形选择流向，再通过保留端点的平滑与等距重采样形成连续河曲；不使用正弦波或固定形状模板。
- 干流分别冻结基准尺寸，包含较宽干流；支流随分叉层级缩小。实际河宽由沿程径流、多级支流累计贡献和局部冲淤共同决定，汇流前后平缓过渡，沿途可多次收窄、展宽，河床深度也随河段变化。较小大陆同步缩小河床和河谷尺度，避免宽河挤占其他流域。
- 支流在更多不同的汇流位置尝试向上游生长；靠近母河时参照母河水位衔接。汇入口检查区分湿河床重叠和干河谷影响，避免将正常支流全部排除；网络有 96 条河道和 3 级支流的上限。
- 两侧河岸使用世界坐标上的多尺度连续扰动，形成不同的凹岸和浅滩；最大影响范围同步用于河道碰撞检查、湖泊相容检查和空间索引。
- 河床使用原版方块，根据局部水深与连续沉积噪声混合泥土、沙子、沙砾、黏土和深处的石头。它是适配本项目水位的材料规则，不是原版表层生成器的逐点复刻。
- 原版陆地群系和通用适配器覆盖的单方块浅水边缘也使用河床材料，避免 Minecraft 四方块群系采样造成水下草块。第三方表层适配器的旧接口仍然可用。

## 验证与预览

单元回归测试通过；Minecraft GameTest 的 8 项必需测试全部通过，包括实际河床材料多样性、下降水位和河岸约束。

新增回归覆盖：非径向河道、河曲差异与支流数量、干流尺寸差异、同河宽窄变化、支流汇入后的渐进展宽、不对称岸线、空间索引边界连续性、沉积物成片分布、种子确定性，以及新版本河流计划的保存与读取一致性。实际区块测试同时检查河床材料种类和水位约束。

`tools/HydrologyAudit.java` 已扩大到整个最大河宽，覆盖宽河两侧岸线。种子 `7331` 与 `345705185492107788` 的侵蚀后审计分别生成 38、89 条河道（均含 8 条干流），均未发现水墙或向干岸漏水。

`tools/RiverPreview.java` 可输出河网总览与逐方块河床预览。种子 `7331` 的干流曲折率（路径长度 / 首尾直线距离）从约 `1.02–1.04` 提升至 `1.05–1.78`。预览不包含侵蚀、植被或结构，不是游戏截图。

生成后的预览位于 `neoforge/build/reports/river-v2/after.png`，模组位于 `neoforge/build/libs/adventureworldgen-0.1.0.jar`，另提供同内容的 `adventureworldgen-0.1.0-r19.jar` 便于区分测试版本。
