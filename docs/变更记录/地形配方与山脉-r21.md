# r21 地形配方、容量包络与连续山脉

生成版本为 `terrain-r21`，实现缓存标识为 `planner-v2-impl-2026-09-08-r21-terrain-recipes-v5`。公共规划格式仍为 `plan-v2`；新增配方记录、山脉路径和参数校验，旧缓存不会作为新计划复用。验收必须使用新测试世界。

## 模板与配置基础

四大规划分类保持不变，具体形状由 12 套配方负责。作者字段定义见[配置说明](../配置说明.md#地形配方参数r21)。`allowed_templates` 与 `allowed_terrain` 取交集；省略前者兼容原有按四分类的配置。每套配方有独立权重、水平尺度、方块高度幅度和细节强度，默认全部启用。

| 分类 | 配方 | 核心形状 |
|---|---|---|
| 平原 | `steppe`、`plains` | 多频 Perlin 调制、两级坐标扰动 |
| 丘陵 | `hills_1` | Perlin × Billow 调制 |
| 丘陵 | `hills_2` | Cubic、细尺度调制、外部 Ridge 调制 |
| 丘陵 | `dales` | 两组 Billow、带符号幂曲线与选择场 |
| 丘陵 | `torridonian` | 平原／丘陵混合、六级阶地、坡度与调制 |
| 台地 | `plateau` | 反相山脊谷地、受限台顶、四级台地与崖面 |
| 台地 | `badlands` | 区域掩码、多级 Steps、主体与细节相乘 |
| 山地 | `mountains_1` | 四层反馈山脊、弱调制与坐标扰动 |
| 山地 | `mountains_2` | Worley 次近距离峰体、山脊表面 |
| 山地 | `mountains_3` | Worley 峰体、24 级受掩码控制的阶地 |
| 山地 | `volcano` | 距离比锥体、逐细胞高度限值、区域扰动、顶部反折火山口、低地山脊 |

上游依据为 FreeTerraForged `43fd42a4d31da5ba36f5ab4d8e4d76d69688e86a` 的 `Populators`、`VolcanoPopulator` 及相关噪声算子。项目保留其函数组合和嵌套扰动顺序，使用自己的确定性哈希、梯度噪声、数学归一化界限和方块高度标度；阶地舍入改为窄窗口连续过渡，台地阶梯使用连续的坡面／崖面参数化，火山使用统一方块幅度。这是适配移植，不声称与上游逐点一致，也未接入可选 fancyMountains 侵蚀噪声。MIT 归属与许可证保留于 JAR 的 `META-INF/NOTICE`。

火山权重为 0.6，默认没有熔岩管、危险状态或专用地表覆盖。火山坡面以裸露砾石岩地和恶地作为填充候选，峰部可选裸岩山峰，仍由温湿度与实际地貌部位筛选。有限大陆不保证每个种子都有全部模板。

## 规划与衔接

执行顺序是海岸 → 山脉走廊与容量 → 配方高度 → 侵蚀 → 水文 → 地貌测量 → 成本、温湿度、群系与结构。规划和区块生成使用同一高度来源。普通陆地继续走原版地表规则，实际浸水河湖床仍保留特殊沉积物处理。

普通配方允许在区域内复合。主、副配方均需符合该区域全部预留需求的交集，并存在共同填充候选；山地不进入普通复合池。连续山脉由独立折线路径和宽度场控制，区域模板生成内部形状，外围连续减弱为山麓。温湿度规划会匹配具体配方与地貌部位的合法填充供给，避免把无法容纳雪地或干燥群系的组合划入相应气候带。风袭丘陵、风袭森林、风袭沙砾丘陵，以及针叶林和两种原始针叶林使用原版随高度变化的降雪判定参与匹配：同一群系在低处属于无雪候选，在达到原版降雪高度后属于雪地候选，湿度供给缓存也区分这两种状态。判定保留原版 1.21.1 的固定温度噪声及浮点运算，并在 GameTest 中与真实群系逐点比对。填充网格在降雪临界高度附近优先采用天气稳定的合法群系，避免细尺度温度噪声导致逐格替换和碎片；仅有海拔敏感群系的自定义配置仍保留合法候选。

容量预留不再裁切生成后的高度，而是在生成前确定基础海拔和幅度。优先天然包络，随后拟合允许配方，狭窄低地再尝试独立区域；失败时继续换位置，耗尽后输出缺失面积、允许配方和拒绝统计。侵蚀安全包络使用现有 `[-12,+8]` 增量界限，低地则计算现有海岸侵蚀衰减后的更小界限。最终水文与精确群系面积检查仍是硬约束证据。

高度过渡使用地形组合对应的范围；细节独立采用 32 方块窄过渡。多区域权重按两两距离差计算，消除最近区域切换带来的三岔交界高度跳变。48 方块的窄群系交错带继续保留。完整算法见[粗细地形生成算法](../粗细地形生成算法.md)。

结构承载群系在选址时还检查天然地面平整度及紧凑内部空间，按最小面积预留至多 64×64 方块的合法内部区域；外围继续竞争生长。这样避免仅有面积却没有建筑宽度的细长承载地。预留只分配群系所有权，不抬高或截平地面；全部必要群系冻结以后才准备建筑，完整占地、入口、地面支撑与适配器约束仍需逐一通过。

计划中保存 `recipe_regions`、`recipe_settings`、`capacity_regions`、`mountain_ranges`。恢复时验证配方记录和参数是否与冻结输入一致；F3 调试显示分类、主副配方、复合权重、地貌部位、坡度、局部高差和山地影响。

## 调参与验证

审计工具为 `TerrainRecipeAudit`、`HeightReservationAudit`、`DemandPlannerAudit`、`FrozenTerrainMetrics` 与 `TerrainRecipePreview`。最终统计、完整规划日志和配方图位于 `neoforge/build/reports/terrain-r21/`。

`recipe-metrics.tsv` 测量独立配方；`frozen-local-metrics.tsv` 测量侵蚀与水文完成后的真实高度场，以 32 方块网格采样干燥陆地中心，计算 64×64 方块邻域的高差中位数／95 分位数、一方块坡度及平坦比例，并统计复合地形和山麓／坡面／峰部。两份指标的采样范围不同，不能把独立配方的全幅高差当作最终局部高差。

高度预留对照使用修改前的 `RegionTerrain` 源码与相同区域、种子、台地分类和 `max_height=112`。统计仅采样安全内部，排除区域过渡：

| 种子 | 旧地形高差 | 新地形高差 | 旧平坦比例 | 新平坦比例 |
|---|---:|---:|---:|---:|
| 9 | 5.54 | 8.98 | 98.11% | 5.45% |
| 7331 | 0.00 | 17.10 | 100.00% | 5.91% |
| 8844 | 18.52 | 13.44 | 3.08% | 6.39% |

平坦判定为相邻一方块在 X、Z 两轴高度变化均小于 0.01。种子 7331 旧实现所有采样点都被截到 104；新实现没有样本停在该截平高度。新配方并不要求所有种子的高差都大于旧配方。

三个种子的独立配方采样范围为 2400×2400 方块。Steppe 高差约 8.2～8.6，Plains 14.6～16.0，Hills1 32.1～32.8，Hills2 41.3～43.1，Dales 39.2～40.9，Torridonian 67.5～72.0，Plateau 63.0～63.2，Badlands 74.0～75.7，山地与火山约 120.8～184.9。台地、恶地和火山局部崖面明显比普通丘陵陡，详见包含中位坡度、95 分位坡度与最大坡度的 TSV。模板分布按主配方和复合区域分别统计，未强制补齐未出现的模板。

降雪边界的填充稳定性回归保留原有上限：1024×1024 方块窗口最多 128 个连通块，微小孤岛占比不超过 1%。种子 1 的临界高度问题修复后，连通块由 239 降至 14，微小孤岛面积由 329 降至 1 个四方块采样格；没有放宽测试标准。海拔降雪还独立对照了原版噪声的 3,354,540 组坐标／高度组合，三档基础温度的结果全部一致。

最终 `./gradlew build --offline` 的 119 项单元测试全部通过，无失败、错误或跳过。种子 9、7331、8844 的完整独立审计均通过必要群系与承载区的有效面积、连通性和保存重载一致性检查。独立审计中的结构使用有界测试占地；真实 Minecraft NBT、地面支撑、原版地表与河流检查由新世界 GameTest 负责，不能混同两种证据。
