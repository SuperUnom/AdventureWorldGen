# r17：四温度带、持续生长与存档直读

必要结构承载群系的后续流程调整见 [r18](结构群系统一规划-r18.md)。本文保留 r17 的统计结果。

本次调整扩大默认必要群系主体，用开放地景填充温度带，并修复进入 READY 存档时重复执行填充和过渡的问题。

## 面积和边缘竞争

- 默认最低面积由 16,384 调为 32,768 平方方块，目标由 131,072 调为 393,216。
- 只写 `min`、`target` 不再隐含 `max=target`。目标是竞争意愿的转折点；目标以下按缺口加权，目标以上按 `-2 ln(面积/目标)` 缓慢降低意愿，直到竞争或合法地形阻断边缘。显式 `max` 继续生效。
- 使用共同尺度比较各群系的边缘成本，避免面积较大的填充竞争者仅因归一化尺度获得不合理速度优势。
- 扩张主要积累坡度、环境变化和路径成本，种子距离的形状项降为次要权重；192 方块连续噪声带来方向变化。填充种子距必要种子的保留空间增大，避免必要主体被过早包围。
- 必要群系仍先共同达到最低面积，再引入填充竞争；面积不足的局部重试和计算预算仍保留。目标不是保证值，合法山地、水系隔离或其他必要群系可能使实际面积低于目标。

## 四种温度与开阔填充

`very_cold`（非常冷）、`cold`（冷）、`medium`（温和）、`hot`（炎热）。连续场使用三个面积分位阈值分类；环境评分仍读取连续温度，保留山体、坡面和局部海拔三种尺度的降温与扭曲噪声。

非常冷群系必须具备原生降雪条件，不能同时声明其他温度类型；冷区使用非雪群系。选址、生长、填充和查询混合统一在 quart 单元中心检查雪带边界，防止两类互相渗入。默认针叶林另设保守海拔硬上限，避免原版高度降温造成冷区降雪。后续雪层、地表和植被由原生群系生成流程处理，没有额外的材料或植被混合。

默认 23 个必要群系加一个出生主体。删除默认必要列表和填充池中的所有风袭群系。填充池为：平原、向日葵平原、草甸、雪原、冰刺平原、积雪山坡、热带草原、沙漠、裸岩山峰。优先当地温度和地形，降低邻近重复惩罚，扩大可变种子间距，使填充成为成片的开放景观。山地仍保留合法的开阔后备群系。

## READY 存档

以前 `GeneratedAdventurePlan` 每次构造都会重新创建 `ClimatePlan` 和 `FillerLayout`，并重新计算边界最低面积保护；即使 `PlanV2Codec` 已读取 READY 数据，也会显示填充、过渡阶段。

现在 `plan-v2` 的 `biome_layout` 保存最终温度场（高程尺度数组、三个阈值、比例及局部修正）、填充归属网格和边界保护地块。加载时直接恢复这些数据，不发出填充或过渡进度，也不再次遍历必要地块计算保护。恢复检查数组维度、标签索引、有限数值、温度阈值及保护地块引用。公共格式名称仍为 plan-v2，内部实现缓存版本已更新；旧计划首次进入需要重新规划，之后相同配置直接读取。

## 验证与地图

复现工具：`neoforge/tools/DemandPlannerAudit.java`。地图来自当前实际海岸、侵蚀、水文和群系查询，结构使用测试占地；等级使用径向软偏好。Minecraft 集成测试另行验证真实适配器、原生气候与运行时成本图。

结果见 `neoforge/build/reports/biomes-r17/`；每个种子包含连续温度图、四类温度图、群系图、地形图、面积表和可重读的完整计划。单元测试覆盖软目标/显式上限、雪带隔离、连续海拔降温、查询混合范围、恢复后字节一致及加载进度；集成测试检查真实群系雪线与 READY 再读。
