# r31：低地、陡海岸与温度带边界

本轮按实际生成观感修正五项地形与群系问题。沙漠仍允许出现河流。

- Steppe／Plains 的自然基准高度分别降到海平面以上 1／2 格，丘陵、台地和山地保留递增基准高度。地形配方的起伏仍完整叠加，必要群系的高度上下限仍由容量预留重新拟合，不通过事后裁切满足。
- 海侧的可见过渡从原来的整个 `seaBand` 缩到 8 格。规划期海床和实际区块的原版海床使用同一 smoothstep，越过岸线后迅速形成明确水深。
- `shore_only` 只识别海岸。河流和湖泊不再生成 beach／snowy_beach 群系；浸水河床仍保留泥土、沙、沙砾、黏土和石头等沉积材料，它们不是陆地沙滩群系。
- 淡水不再强制提高用于群系分配的湿度，也不再把沙漠排除在河道下方。必要群系的生长可以跨越至多 96 格的河面，但水下格不计入面积，目标岸的温度、湿度、地形、结构保护等硬准入仍逐格验证。
- 同温度带填充竞争由四方向网格扩张改为带真实对角距离的八方向扩张，先按温度档选择，再比较连续气候代价。大尺度边界减少水平／垂直折线，查询层已有的双尺度连续域扭曲继续提供小尺度弯曲。
- 河源前 72～152 格按种子渐进扩大河床、河岸和河谷；源点河床同时更浅，避免满宽河道和满宽河谷突然以圆帽结束。

验证覆盖低地最低高度、8 格海床下降、仅海岸沙滩、河流不改写湿度、必要群系跨河且不计水下面积、河源宽深渐变、硬地形限制与确定性 golden vectors。完整单元测试共 154 项通过。
