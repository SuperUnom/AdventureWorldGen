# r11：规划崩溃修复

针对 `crash-2026-09-08_02.39.33-server.txt`。报告中的世界种子是 `4126649097427443736`，异常为必须群系落位阶段的 `NO_SOLUTION_IN_DOMAIN`。

## 修复

1. **成本细化窗口偏移。** 256 方块窗口的起点原来按 `floorDiv(x,256)*256-128` 计算，但查询坐标可能位于窗口之外。改为 `floorDiv(x+128,256)*256-128`，负坐标同样覆盖完整窗口。
2. **出生点成本被抬高。** 原来只从细化窗口周界导入全局成本，即使查询出生点，也要计算一次到周界再返回的绕路。现在同时导入窗口内的全局粗网格节点成本，再运行局部细化。
3. **出生地块跨入禁用地形。** 成本修复后，崩溃种子的 27 个必须群系可以落位，但出生群系的固定居中地块仍跨入平原群系不允许的地形。现在先检查原位置，再在中心域内按 16 格、4 格两级尝试平移地块。地块必须继续覆盖原点，每个归属单元都满足硬地形限制；玩家出生点和成本源保持原点，掩码形状及面积不变。
4. **出生区域预留过晚。** 另一个最小复现表明，附近的必须森林可先占用出生地块。出生群系改为先保留完整掩码，再安排结构承载区和普通必须群系；普通需求的随机序号保持原值。
5. **失败诊断。** 必须群系搜索失败时，异常消息包含群系 ID、地块 ID、冒险等级、世界种子和搜索诊断。规划开始日志增加种子。

必须群系数量、面积、冒险等级和群系地形规则没有放宽。实现版本更新为 `planner-v2-impl-2026-09-08-r11-cost-grid-spawn-reservation`，旧实现的计划缓存不能直接作为新版结果使用。
