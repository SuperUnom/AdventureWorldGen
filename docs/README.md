## 4．维护约定

- 每类事实只在一个位置完整定义：产品语义在设计原则，作者字段在配置说明，求解步骤在算法文档，数值在内部契约，落地与持久化在运行时契约，完成证据在验收指南；其他页面只保留摘要并链接原定义。
- 新增一轮改动写入 `变更记录/`，命名为 `主题-rNN.md`；未编号的中间轮次沿用现有命名并在此索引登记。
- 实验与外部参考分别放入 `实验/`、`参考资料/`；确认采用的结论必须回写到当前定义，不能只留在记录里。
- 链接一律使用相对路径。移动文件后必须重新核对全部相对链接与锚点（本仓库用脚本检查断链，锚点用 `<a id="...">` 显式定义）。
- 文档与实际接口不一致时，先确认哪一侧是产品决定，再改另一侧；不能仅凭文件时间或代码现状自动决定产品语义。
