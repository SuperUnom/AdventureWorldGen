# 道路系统

道路在群系、结构宏观锚点和出生确定后规划，READY 发布前完成施工几何验证。
`RoadPlanner` 不改变群系归属、结构位置或用于冒险等级的自然地形到达成本。

## 目的地与连接

profile 在必须群系和结构条目下选择道路连接，字段见 [Profile 道路配置](../reference/profile.md#roads)。
出生自动作为路网根节点；群系节点从该 ID 已有 patch 中选择靠近出生的合法位置。
不再接受自定义方块坐标目的地，也不在 filler 中补选缺失的目的地。
结构节点连接经过寻路选择的外围接入点；作者可声明入口方向，但不会自动推断门口或内部通道。

条目的 `road.required` 为真且道路启用时，目的地缺失或不能接通会阻止 READY 发布。可选目的地可以缺席，原因保存在
`RoadPlan.skipped` 并输出日志；无法连回出生的独立道路分量不会发布。
重合目的地共享已有节点，并记录重合诊断。

先评估节点最近的少量连接，额外保留必需节点之间的候选；必需骨架及其有界连通修复先于可选支路。
骨架从出生分量逐步扩展，每次提交后锁定结构入口，再搜索下一条边，避免预先搜索的异侧入口大量作废。
候选按搜索代价稳定排序，随后有界补充不同连通分量间的候选。可选环路受额外长度比例约束，并要求显著减少已有路网绕行。
环路收益按已施工列的实际连通距离判断，计入中途交叉口的通路。
这不是连续地形上的全局最优路网证明；后续施工冲突也可能拒绝候选边。

## 平面形状与高程

`RoadSearch` 使用包含来向的加权 A*，惩罚急转弯；先粗后细，并有界扩大搜索范围。
启发式轻度加权用于在固定操作预算内优先向目标推进，不承诺最短路径。找到可施工直连后不再为同一节点对搜索更便宜的绕行。
沿路采样高度、横向宽度和水体，禁止海洋、岩浆、危险地形和结构保留区域。
长度、高差、转弯和过河成本参与候选比较，不直接复用自然地形行走成本的通行规则。

`RoadShape` 在合法干地走廊内简化折点、圆滑转角，并对较长直段加入长跨度、小幅度缓弯。
偏移使用世界 seed 和稳定端点身份，端部偏移与切向偏折收敛到零；桥段保留直线。
`maximum_bend_detour` 限制装饰性缓弯相对对应直段的增量，不限制绕山寻路的总绕行。
曲线不能通过全宽验证时退回可行路线，不能为了弯曲放宽地形限制。

`RoadJunctions` 检查候选与已有中心线的重复相交。在两次相交之间，若复用已有路段的距离不超过
原候选段的 `maximum_bend_detour` 倍，则合并到已有走廊，避免独立缓弯产生狭长双线环。
保留单次交叉和能够显著缩短绕行的路线；合并结果仍须通过完整施工验证。

`RoadConstruction` 把中心线变成完整道路列，陆路另有窄路肩，桥梁保持核心通行宽度。
出生附近的路面固定到自然地面顶层方块，不使用玩家出生时预留的悬空高度。
陆路在坡度求解前，对施工走廊内 9×9 邻域的自然干地顶层高度取中值，滤除短凸起与凹坑；
每次从自然地形计算，避免重复评估累计削低路面。宽山坡保留，挖填上限与桥下净空仍是硬约束。
高程求解同时约束自然地面附近的挖填范围、纵横坡度和出生路面；候选道路与已选骨架一起求解路口高程，
直到 READY 发布才冻结，避免先量化的旧路面把本来可施工的交叉口锁死。候选验证不修改已有输入。
最终整数路面检查四邻接连通和相邻高度差，保存路面、支撑底部和净空顶部。
原始地形查询不受道路改变，施工覆盖由冻结列提供；道路地基不反馈到原始成本图。

河流只有在跨度、两岸接坡和施工范围允许时才能形成短桥。桥面和梁体位于水面之上，
不把桥下水体填成路堤。湖泊、湿地、海洋、隧道和大型高架不在当前施工范围内。
同高路口通过共享道路列汇合；当前不提供立交，也不保证每个路口都呈现特定的 Y/T 造型。

## 结构接入契约

结构类型通过纯 `StructurePlanningInfo` 分别提供水平禁入范围和可选接入信息。
资源位于 `data/<namespace>/adventureworldgen/structure_planning/<path>.json`，ID 对应结构 ID：

```json
{
  "footprint": {"min_x": -32, "min_z": -32, "max_x": 40, "max_z": 32},
  "road_access": {
    "margin": 4,
    "connector_length": 16,
    "entrances": [{"x": 0, "z": -48, "facing": "north"}]
  }
}
```

`footprint` 是相对宏观锚点的包含端点的方块范围，表示道路不得进入的保守范围；
必须包含原生起点包围盒与地基影响，不能把裸 pieces 尺寸当作完整禁入范围。
它独立于 `road_access`，未启用道路连接的结构也参与规划避让。
没有可信范围的结构不会被自动猜测尺寸；需要连接时缺少范围会失败，未连接时仍保留执行期冲突检查。

`margin` 是接入位置的施工外缘相对禁入范围的最小净距，候选中心线还包含道路半宽、路肩和整数栅格余量。
`connector_length` 指入口沿朝外方向延伸的局部直线段长度；局部段只走合法干地，
和宏观路线一起验证挖填、坡度、路口高度及完整施工列。它不是区块期补路。
字段范围统一由 `StructurePlanningInfo` 校验。

`entrances` 可省略，省略时每边取少量代表点。显式入口使用相对 anchor 的 XZ 偏移和
`north/east/south/west` 朝外方向；独立 Template 的入口坐标位于未旋转模板坐标系，随模板旋转。
入口必须在完整禁入范围之外并留足道路全宽与 margin；当前不允许局部段穿入地基，也不推断门槛 Y。
所有声明入口都非法时不会悄悄改接任意边界。非 Template 的声明使用世界轴方向，Java 结构的
原生 chunk 定位偏移须由声明者计入，不能假定 anchor 是实际原点。

候选先进行直连预筛，再进行有界 A*；已有可行路线可用几何距离下界剪枝。
候选经过寻路、整形和施工验证后按搜索代价稳定比较。一个结构最终只保留一个接入点：
首次提交连接后锁定该点，其他边不能把结构两侧当作免费的内部通道。
端点锁定后，异侧候选必须重新寻路到锁定入口，再经过完整整形、局部连接和施工验证；
不再在曲线处理后追加矩形外围折线。重新寻路与其他候选共用全局预算，失败仍由有界连通修复处理。
候选比较与连接顺序是有界启发式，不证明最终建设成本或全局路网最优。

独立 `TemplateStructure` 在启动资源预检时导出四种旋转或固定旋转下的准确水平几何与禁入范围。
规划与执行共享旋转选择；禁入范围包含原生结构调整以及实际启用的 support/margin。
作者额外声明的范围与自动结果取并集，不会覆盖掉资源范围。纯 DTO 进入输入摘要，planner 不读取 NBT。
固定大小模板的 XZ 几何不等于原生生成有效性证明，Y、群系和引用半径仍由执行期验证。

### 原生实例预检与重放

生产启动在群系归属、混合与自然地形确定后，由 `StructureInstancePreparation` 调用原生执行器验证起点。
使用独立的自然地形查询生成器：不等待正在构建的 READY，不读取道路覆盖，不写方块或区块。
初始候选无效时，在原承载群系内按稳定顺序尝试邻近锚点；搜索半径和原生调用次数均有固定上限，
检查作者群系集合、干地、数量、同类型间距和起点区块冲突。搜索发生在冻结之前，失败明确报告结构实例。

预检只导出每实例的纯 `StructurePlanningInfo`：原生包围盒包含实际地基影响，动态结构用它替代类型级保守方框。
没有显式入口时，接入点对准各方向最外侧的真实部件，并在完整影响范围外留足道路宽度与 margin，
避免停在包围盒的空角落。它不推断建筑门口，也不穿过村庄内部。
模板作者额外范围仍取并集；显式入口保留其约束。纯算法工具未连接游戏资源时仍使用类型级声明，
其结果不能替代原生实例预检。

预检 pieces 用后丢弃，不保存到全局计划，不作为另一份执行权威。
区块执行使用相同 seed、资源和自然查询视图重建起点，核对冻结范围并交给原生区块管线保存和放置。
READY 恢复只读冻结锚点与道路，不重新做候选搜索。活动生成资源摘要纳入计划输入身份，
资源或算法改变不会命中旧 READY，也不迁移已经生成的区块。

旧 `exclusion_radius` / `approach_distance` 资源仍可读取，转换成正方形禁入范围和两者之差的 margin；
不能与新 `footprint` 混用。新候选规则不承诺复现旧圆周端点。

执行桥接层核验真实起点（已包含原生调整与显式地基影响）是否处于冻结实例范围，并检查道路冲突，
不再在已接管起点的完整影响范围外统一叠加另一层固定退让。超出声明或冲突仍明确失败。
未接管原生随机结构继续使用保守的额外碰撞余量。运行时检查不能因规划期有范围就删除。

## 区块执行与存档

`AdventurePlanView` 提供道路点查询和区块范围查询；`RoadIndex` 从冻结列重建空间索引。
区块列与基础高度/基础列查询消费同一覆盖，桥下保留原始空腔和水。
原生 surface rules 完成后，`RoadWorldgen` 恢复路面、支撑、台阶和通行净空。
陆路路肩使用砂土，陆路/桥梁台阶分别使用圆石/橡木台阶。
普通生成材料配置见 [Profile 的道路字段](../reference/profile.md#roads)。

carver 在道路区块及邻近区块避让。`RoadDecorationMixin` 在 `WorldGenRegion.setBlock` 按写入目标
检查冻结保护范围，因此也能阻止相邻区块伸来的树干、树叶或地物堵路。
绕过该写入入口的第三方地物不在这个保护承诺内。
路面只在区块生成阶段执行，不在普通加载时重铺；玩家建造和拆除不受该生成期保护限制。

长距离道路不包装成一个原生结构起点，不借助区块加载事件放置，不建立第二份已生成区块清单。
全局计划保存完整施工列和路网元数据，区块保存已生成方块。恢复只重建索引，不重新寻路。
启用道路会启用世界级生成输入保护，沿用现有生成身份文件，详见
[执行身份](runtime-worldgen.md#structures) 与 [冻结格式](../reference/plan-v2.md)。已有世界不迁移道路。

## 预算和失败

节点数、冻结列数和地形采样次数都有预算；它们的作者设置进入规范输入。
每个逻辑节点对的所有入口尝试共用采样上限，单个入口另有较小额度，候选组合数量有固定上限；
每次 A* 仍有搜索状态和扩展次数上限，全局预留部分采样预算给最终施工。
缓存命中也计入相同采样次数，缓存不能改变何时结束搜索。调整固定搜索常量须更新实现身份。

可选连接耗尽自身预算会记录诊断；全局资源耗尽仍会明确失败，不发布未经验证的结果。
搜索域不足、采样预算耗尽、非法目的地、结构范围冲突及坡度/挖填失败分别诊断，
不能把任一有界失败解释成全大陆无解。

## 验证与预览

`RoadPlannerTest` 检查缓弯、绕行、缓坡接入、短桥、结构范围、稳定顺序和预算；
`RoadConfigTest`、`RoadPersistenceTest` 检查输入身份、严格字段与非空路网 READY 往返。
roads GameTest 检查实际区块顺序、基础列一致性、邻区块写入保护、桥下水体与玩家修改保留。

`RoadPreview` 使用同一个生产 planner 渲染合成地形示例和纵坡，也可读取真实冻结计划：

```bash
./gradlew -I tools/planning-benchmark.gradle writePlanningBenchmarkClasspath
AWG_TOOL_JAVA_OPTS=-Djava.awt.headless=true ./tools/run-audit-tool.sh RoadPreview build/reports/roads/road-shapes.png
AWG_TOOL_JAVA_OPTS=-Djava.awt.headless=true ./tools/run-audit-tool.sh RoadPreview <profile.json> <plan-dir> <output.png>
```

`<plan-dir>` 是包含 manifest 与压缩 payload 的叶目录；配置须与计划匹配。
预览显示冻结施工列，不是 Minecraft 客户端截图，也不等于对第三方地物或玩家实际行走的全面验收。
分组测试命令见 [测试指南](../development/testing.md#gametest)。
