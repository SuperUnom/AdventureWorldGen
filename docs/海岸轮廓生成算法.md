# 海岸轮廓生成算法

[文档总览](../README.md) · [地形修复与验证](变更记录/地形修复-r6.md)

状态：2026-09-08，r9。原先的周期径向海岸已被替换。固定参考 FreeTerraForged 提交 `43fd42a4d31da5ba36f5ab4d8e4d76d69688e86a` 的 `UpliftContinentGenerator.createWarp/apply`；采用其二维扰动细胞边缘场思想，自有噪声与单大陆约束，不逐点复制上游世界。

<a id="section-1"></a>
## 目标与边界

大陆由一个经过二维坐标扰动的 Voronoi 单元边缘场生成。提取包含原点的闭合外轮廓，最后整体等比缩放，使最远点距原点约 `world.radius`。默认值 3000。缩放不会把任何局部截成圆弧，轮廓也不再要求每条原点射线只穿过海岸一次；允许凹湾与回折岸线。

只选取包含原点的大陆连通分量，不加入离岸岛屿；轮廓内部孔洞由水文系统负责，不从大陆场直接发布。外围固定为 `minecraft:ocean`。

<a id="section-2"></a>
## 连续大陆场

在无量纲坐标中，中心点固定为原点，八个邻居的格点间距为 1.9，单轴抖动区间为 ±0.475。邻居使用世界种子与稳定键派生。对所有邻居计算中心 Voronoi 单元的有符号边缘距离，以 0.08 宽度的平滑最小值连接拐角，随后内缩 0.10。

<a id="section-3"></a>

采样坐标先经过两轴独立的梯度噪声扰动：4 个 octave，初始尺度 0.9，倍频 2.2，初始每轴幅度 0.62，逐层乘 0.42。低频产生大海湾与半岛，高频产生较小弯折；不再沿角度添加高频余弦，因此不会产生整圈重复的径向尖齿。

## 方块尺度的分形细节（r9）

宏观场确定大海湾后，`FractalCoastWarp` 在世界坐标上叠加五层旋转剪切；尺度依次为 384、160、64、24、8 方块，幅度为 120、70、36、16、6 方块。每层使用两个方向不同的独立噪声场，方向按黄金角变化。半径小于 1500 时幅度整体乘 `R/1500`。

剪切只沿一个方向位移，位移值由横向坐标决定，因此可以精确逆变换，Jacobian 行列式为 1。复合映射不会把原海岸折叠为交叉边；相比单次大幅二维位移，它允许更强的局部湾口。幅度随尺度缩小的衰减较慢，使小湾中仍有更小的弯折。它是项目自己的有限尺度分形细化，不是上游算法的逐点移植，也不宣称在方块尺度以下无限分形。

变换前沿轮廓以最多 0.5 方块步长插入采样，变换后的相邻分辨率轮廓参与同一精度检查与简化。每条海岸都使用种子冻结，运行时不再另加偏移。

<a id="section-4"></a>
## 固定轮廓与精度

在 `[-2,2]²` 中以 marching triangles 提取零等值线，使用共享网格边 ID 连接线段，避免 saddle 单元的歧义。每个闭合分量单独追踪，选取包含原点的外轮廓。

起始分辨率 512，逐次倍增，最大 4096。比较相邻两次轮廓的双向顶点到折线距离，要求不超过 `min(2,R/1024)` 方块；这是数值收敛检查，不宣称解析 Hausdorff 误差证明。等比缩放后按剩余误差预算简化折线，最多 16384 个顶点。预算不足时报告错误。

`Coastline` 使用一般多边形射线判定及 BVH 最近线段索引。点内外、陆海距离、成本边界和方块过渡都使用这份持久化折线。不得恢复旧的“按极角直接找到唯一边”查询。

<a id="section-5"></a>
## 海岸高度与海洋

陆侧岸带宽度 `min(128,R/8)`，高度由海面平滑接至区域地形；侵蚀在海平面附近衰减，保持干陆地不低于海面。水面物理上表面为 64，顶层水方块 y=63。

海侧在越过岸线后的 8 格内接至原版海洋海床；`seaBand` 仍作为海岸搜索和饱和查询范围，不再决定可见浅海宽度。外海使用原版 Overworld 噪声路由、含水层、噪声洞穴、矿脉及表层规则，仅把大陆度固定为海洋范围 -0.65，并统一水位至 64。规划期海床是近似值；区块生成及 `getBaseColumn/getBaseHeight` 使用同一 8 格混合因子接入原版实际列。河口切削延伸进近海，防止岸线处出现水下堤坝。

<a id="section-6"></a>
## 出生预留

首先要求预留半径小于 `R/2`，然后检查最终折线到原点的最短距离是否大于预留半径。失败时报告不兼容，不强行压平海岸或挪动出生点。

<a id="coast-samples"></a>
## 成本与样本

按最终折线等弧长采样，目标间距 64 方块，最多 16384 个样本。可达海岸样本成本的中位数继续作为冒险等级参考。位置候选不能只沿固定圆环搜索。
