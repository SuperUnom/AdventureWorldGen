# r9：分形海岸与群系地形规则

本次针对小尺度海岸过于光滑、沙漠覆盖高山，以及默认必须群系不足进行修改。

## 海岸

保留不规则单大陆的宏观轮廓，使用五层旋转剪切细化到约 8 方块尺度。大海湾中出现更小的湾口、岬角，细节不再只是一条缓慢变化的圆弧。每步剪切可逆，防止强位移把轮廓折叠；所有层共同参与折线精度校验。默认最大延伸仍为 3000，外海仍由原版海洋生成。

[三级放大图](../neoforge/build/reports/coast-r9/coast-detail.png) 使用用户种子 `345705185492107788`，同一海岸位置 `(2296,533)`，宽度依次为 2048、512、128 方块。图来自冻结海岸的精确查询，是算法诊断图，不是游戏截图。最右图仍有约 8～24 方块的局部弯折。

该种子的海岸折线为 6964 个顶点；相邻分辨率估计误差加简化容差约 1.196 方块，低于 2 方块上限。沿岸采样间距从 256 缩小到 64，再缩小到 16 时，测得周长依次约 20160、22845、25669 方块；两个尺度的周长均增长约 12%，避免只凭整体轮廓判断细节。

## 地形规则与默认群系

新增可选 `biomes.terrain_rules`，按群系 ID 设置 `allowed_terrain`，并可设置 `min_height`、`max_height`。允许的地形为平原、丘陵、台地、山脉。规则作用于必须地块、出生、结构承载区和填充区；不配置时兼容旧行为。最终每个 4×4 群系单元中心都经过规则检查。河湖继续覆盖原版河流/冻河群系。

默认沙漠只允许平原和台地，地面高度不超过 Y=112。裸露与冰雪山峰只允许山脉模板，并增加石头、积雪、冰和砂砾等相应表层适配。

默认必须群系共 27 种，每片配置面积为 16384～32768 平方方块：

- 森林、繁花森林、桦木森林、原始桦木森林、黑森林。
- 针叶林、积雪针叶林、原始松木针叶林、原始云杉针叶林。
- 丛林、稀疏丛林、竹林、红树林沼泽、沼泽。
- 樱花树林、雪林、热带草原、热带高原、风袭热带草原、风袭森林。
- 草甸、积雪山坡、尖峭山峰、冰封山峰、裸岩山峰、风袭丘陵、风袭沙砾丘陵。

这里覆盖主世界树林；不把下界绯红森林和诡异森林放入主世界。

完整配置见 [default.json](../neoforge/src/main/resources/data/adventureworldgen/adventureworldgen/profiles/default.json)，字段约束见 [配置说明](配置说明.md#required-biomes)。用数据包覆盖 `data/adventureworldgen/adventureworldgen/profiles/default.json` 即可修改规则。

## 落位与验证

群系不再通过建筑用的平坦度门槛，山脊和陡坡可以承载山地群系。结构优先预留实际承载区，再安排必须群系；取消结构远离所有群系中心的额外排斥，保留区域冲突、建筑占地与配置间距检查。

测试包含配置解析与规范化、全地块地形约束、填充后备池、山脊群系落位、海岸多尺度粗糙度，以及原有河岸、群系过渡和原版外海回归。两个生产种子逐格核对 27 种必须群系的实际归属与面积，另在大陆内抽查填充群系地形条件。

验证结果：`test runGameTestServer` 通过，共 62 项单元测试、6 项 GameTest；`build` 通过。生产种子 `7331` 规划约 95 秒，用户种子 `345705185492107788` 约 116 秒（本机测试值，实际耗时取决于机器和配置）。用户种子的各群系位置及实际面积见 [坐标表](../neoforge/build/reports/coast-r9/biomes-345705185492107788.tsv)。

本轮未进行完整新世界的游戏内飞行巡查；海岸视觉检查使用上述诊断图，方块水体与外海使用 GameTest 验证。

## 使用

用 `adventureworldgen-0.1.0-r9.jar` 替换旧 JAR，mods 目录只保留一个本模组文件。请新建世界检查效果；旧区块不会因为修改规划算法而重新生成。已有数据包覆盖默认 profile 时，需要同步更新配置，才能获得新增的默认群系和规则。
