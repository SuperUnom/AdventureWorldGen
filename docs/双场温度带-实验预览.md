# 双场温度带：第一版实验预览

先生成可比较的连续温度图与四档温度带图，供视觉调参。本实验在工具中实现，尚未替换正式 `ClimatePlan`，也不修改保存的世界计划。

## 两个场

1. 旋转纬度场：将世界坐标旋转为横跨温度带的 `u` 和沿温度带的 `v`。全部边界使用相同的 `u + 144 × noise(v)`，因此方向一致、边界轻微弯曲且不会互相交叉。暖向为 +X 朝 +Z 旋转 32°，可通过命令行改方向。
2. 海拔降温场：复用当前计划中的有效高度（25% 局部高度、55% 坡面平滑高度、20% 山体平滑高度），以 Y=76 为基准，每升高 100 格降低 2.5 温度单位；基准以下不增温。

纬度场为六个平台，温度依次为 0.5、2.3、4.1、5.9、7.7、9.5。平台之间以 smoothstep 连续连接；五个阶梯边界中心位于 `u = -1800, -900, 0, 900, 1800`，阶梯间距 900 格，过渡宽 495 格，沿带噪声尺度 2160 格。

```text
T_lat = 0.5 + 1.8 × Σ smoothstep((u + 144 × noise(v) - i × 900) / 495 + 0.5)
        i = -2, -1, 0, 1, 2
T_height = -0.025 × max(0, H_effective - 76)
T = clamp(T_lat + T_height, 0, 10)
```

这里的温度是相对指数，不是摄氏度。输出四档：严寒 `[0,2.5)`、寒冷 `[2.5,5)`、温和 `[5,7.5)`、炎热 `[7.5,10]`。连续图与分档图读取同一次采样的最终温度，没有分别拟合面积，也没有额外加入出生点、群系需求或积雪供给修正。

## 实际样本

使用 r25 最终基准计划的种子 7331、半径 3000 的真实侵蚀及河流地形；画面范围为 X/Z ±3200，900×900 个像素中心采样。外海以灰蓝色遮罩，内陆水体保留温度。

- 严寒 34.4%，寒冷 34.5%，温和 28.1%，炎热 3.0%（非外海样本面积占比）。
- 最终温度范围 0–8.7583，最大海拔降温 3.7390。
- 海拔项使 23.73% 的非外海样本相对单独纬度场改变温度档位。
- 当前暖区较少，是这组纬度布局和降温强度的实际结果；尚未为了四档均分而自动校准。

工具检查了数值有限、海拔项只降温、纬度阶梯沿横向单调、四档均出现。已查看生成图片，中文、图例与坐标正常。此为出图实验验证，不代表正式群系分配兼容性验收。

## 复现与调参

在仓库根目录执行（使用已有构建的运行时 classpath）：

```sh
java -Xmx2g -Djava.awt.headless=true \
  -cp "$(cat neoforge/build/planning-benchmark-classpath.txt)" \
  neoforge/tools/TemperatureFieldPreview.java \
  neoforge/build/planning-r25-final/adventureworldgen/plans/adventureworldgen_default \
  neoforge/build/reports/temperature-two-fields-v1 32 900 0.025
```

末尾三个参数为暖向角度、纬度阶梯间距、每格海拔降温。输出 `temperature.png`、`temperature-bands.png`、并排 `comparison.png`、`parameters.json` 和原始 `fields.bin`。二进制数据逐行存储大端 float 高度、纬度温度、海拔降温量、最终温度，以及一个 byte 的非外海标记。后续可在同一地形上调整带宽、方向与降温强度。

## 第二版：减轻整体偏冷

根据第一版偏冷的反馈，纬度场整体增加 1.4，海拔递减系数从 0.025 降为 0.018（每百格降温 1.8）。方向、带宽、地形、配色与四档阈值沿用第一版。

```text
T = clamp(T_lat + 1.4 - 0.018 × max(0, H_effective - 76), 0, 10)
```

| 温度带 | 第一版 | 第二版 |
|---|---:|---:|
| 严寒 | 34.4% | 8.5% |
| 寒冷 | 34.5% | 35.9% |
| 温和 | 28.1% | 40.4% |
| 炎热 | 3.0% | 15.3% |

同为 225,480 个非外海样本，百分比独立四舍五入。海拔改变档位的比例为 16.79%，最大降温量为 2.6921。四档仍均出现，数值和纬度带顺序检查通过，并已查看新图。

工具新增末尾可选参数 `temperature offset`，默认 0，保留第一版复现参数；第二版命令如下：

```sh
java -Xmx2g -Djava.awt.headless=true \
  -cp "$(cat neoforge/build/planning-benchmark-classpath.txt)" \
  neoforge/tools/TemperatureFieldPreview.java \
  neoforge/build/planning-r25-final/adventureworldgen/plans/adventureworldgen_default \
  neoforge/build/reports/temperature-two-fields-v2 32 900 0.018 1.4
```

第一版图片与数据保留在原目录，第二版存入 `temperature-two-fields-v2`，仍为实验预览。

## 第三版：山脚、山腰、山峰分带

目标是在多处高山上形成不同海拔温度带。纬度场保持相同方向、带宽与边界弯曲，冷暖跨度缩至 60%，基准偏移改为 +2.6；海拔项改为连续的分段线性降温：有效高度 Y76–110 每百格降温 1.2，Y110 以上每百格降温 6.5。Y110 处温度连续，只改变递减率；未给山峰另画固定颜色区域。

```text
R = max(0, H_effective - 76)
T_latitude = 5 + 0.6 × (T_lat - 5) + 2.6
cooling = 0.012 × R + (0.065 - 0.012) × max(0, R + 76 - 110)
T = clamp(T_latitude - cooling, 0, 10)
```

四档面积为严寒 5.3%、寒冷 14.1%、温和 48.8%、炎热 31.8%。纬度与海拔叠加仍使用连续值，最终才分档；山地温差增强，低地整体更暖。这是视觉生成参数，不是地球大气递减率的物理标定。

使用 `audit_temperature_mountains.py` 从图中选择三处相距至少 700 格、地表高度超过 Y190 的高点。在各高点周围 600 格内，分别统计实际地表 Y76–110、Y130–170、Y190 以上的样本作为山脚／山腰／峰区代理。三个区域可能包含同一山脉的不同山峰，统计范围也可能重叠；不是独立山脉识别或登山路线验证。

| 高点 X/Z | 山脚平均温度 | 山腰平均温度 | 峰区平均温度 |
|---|---:|---:|---:|
| -18 / -1163 | 6.32 | 4.09 | 1.06 |
| -1113 / -1490 | 5.18 | 3.64 | 0.70 |
| 651 / -900 | 7.41 | 4.82 | 1.38 |

三个区域的三个高度组分别以温和、寒冷、严寒为面积最多的档位。较矮山丘或其他种子的山脉不保证均有三档，取决于实际高度差和所在纬度。已查看最终两图，数值、海拔只降温及纬度带顺序检查通过。

```sh
java -Xmx2g -Djava.awt.headless=true \
  -cp "$(cat neoforge/build/planning-benchmark-classpath.txt)" \
  neoforge/tools/TemperatureFieldPreview.java \
  neoforge/build/planning-r25-final/adventureworldgen/plans/adventureworldgen_default \
  neoforge/build/reports/temperature-mountain-belts-v3 32 900 0.012 2.6 110 0.065 0.6
python neoforge/tools/audit_temperature_mountains.py \
  neoforge/build/reports/temperature-mountain-belts-v3
```

新增末尾三个可选参数为加快降温的有效高度、该高度以上的递减系数、纬度温差比例；省略时保持旧版参数含义。统计保存在 `mountain-audit.json`。本版仍仅更新实验工具，尚未接入正式群系规划器。

## 第四版：增加重复条状温度带

为了在地图上出现更多组冷暖条带，新增 `repeating` 模式：横跨条带方向循环使用基础平台 `0.5 → 5 → 9.5 → 5 → 0.5`，每级间距 350 格，一个完整冷暖周期为 1400 格。平台之间仍使用 smoothstep 连续连接，过渡宽 192.5 格。各带共用同一沿带坐标扰动，幅度 56 格、噪声尺度 840 格，整体方向仍为 32°。这是重复的模拟纬度场。

第三版的纬度温差倍率 0.6、偏移 +2.6、低地与高山海拔降温参数均保留。最终四档面积为严寒 4.6%、寒冷 18.9%、温和 41.9%、炎热 34.5%（独立四舍五入）。已检查重复周期、跨带连续性、数值范围、海拔只降温与四档出现，并查看两张最终图。

相同三处峰区的山脚／山腰／峰区平均温度分别为 `5.82 / 4.37 / 1.55`、`7.88 / 6.33 / 2.64`、`8.27 / 5.31 / 1.98`。重复条带会横穿山脉，因此高度组内会混入不同纬度温度；第二处的山脚与山腰面积最多的类别均为炎热，不再声称每处高点的三个高度组都以不同类别为主。海拔降温保持原有强度，具体局部分带由两个场叠加得到。

```sh
java -Xmx2g -Djava.awt.headless=true \
  -cp "$(cat neoforge/build/planning-benchmark-classpath.txt)" \
  neoforge/tools/TemperatureFieldPreview.java \
  neoforge/build/planning-r25-final/adventureworldgen/plans/adventureworldgen_default \
  neoforge/build/reports/temperature-repeated-belts-v4 32 350 0.012 2.6 110 0.065 0.6 repeating
python neoforge/tools/audit_temperature_mountains.py \
  neoforge/build/reports/temperature-repeated-belts-v4
```

最后的模式参数省略时为 `ordered`，旧版仍可复现。图片、参数和抽样统计保存至 `temperature-repeated-belts-v4`；仍为实验预览。

## 第五版：稍减条带数量、加大扭曲

带宽从 350 增至 500 格，完整冷暖周期从 1400 增至 2000 格，沿跨带坐标的条带密度减少 30%。扭曲幅度从 56 增至 450 格，沿带噪声尺度设为 950 格，产生更明显的大幅弯曲。所有边界继续共用同一个沿带位移场，保持总体方向一致；实际位移为 `450 × noise(v)`，450 是参数幅度，不代表每个位置均移动 450 格。

海拔降温、纬度偏移及温差倍率沿用第四版。最终四档面积为严寒 4.4%、寒冷 22.0%、温和 41.7%、炎热 31.8%，百分比独立四舍五入。已检查数值、连续性、重复周期与四档出现，并查看最终两图。三处峰区的山脚／山腰／峰区平均温度分别为 `7.10 / 6.10 / 2.97`、`6.20 / 4.68 / 1.54`、`8.40 / 5.23 / 1.56`；第一处山脚与山腰的主要类别同为温和，温度带位置仍由纬度与海拔共同决定。

工具新增末尾两个可选参数：扭曲幅度、扭曲噪声尺度。省略时保持此前的 `spacing × 0.16`、`spacing × 2.4`。

```sh
java -Xmx2g -Djava.awt.headless=true \
  -cp "$(cat neoforge/build/planning-benchmark-classpath.txt)" \
  neoforge/tools/TemperatureFieldPreview.java \
  neoforge/build/planning-r25-final/adventureworldgen/plans/adventureworldgen_default \
  neoforge/build/reports/temperature-warped-belts-v5 32 500 0.012 2.6 110 0.065 0.6 repeating 450 950
python neoforge/tools/audit_temperature_mountains.py \
  neoforge/build/reports/temperature-warped-belts-v5
```

本版图片和数据保存至 `temperature-warped-belts-v5`，仍为实验预览。

## 第六版：取消大致平行要求，改用二维自然温度场

根据反馈取消共用横向位移、固定跨带方向和周期阶梯。新增 `organic` 模式：X/Z 两轴分别采样独立二维梯度噪声，先做尺度 1150、幅度 850 格的位移，再在已扰动坐标上做尺度 483、幅度 187 格的细一级位移。温度由两层二维梯度噪声按 0.8/0.2 混合，第二层坐标旋转约 36.87°，形成不同走向和宽窄的冷暖区域。

基础特征尺度参数为 450 格：主温度噪声尺度 1035 格，采样坐标缩放为 `(0.72x, 1.2z)`；次温度噪声尺度 585 格。局部可形成狭长温区，但不保证条带数、平行性或固定重复周期。连续温度表达为 `T_base = 5 + 0.6 × 4.5 × tanh(3.2 × field) + 2.0`，再叠加第五版相同的海拔降温，最后限制为 0–10 并分四档。

为保持冷暖比例接近第五版，基础偏移从 +2.6 调为 +2.0。最终四档面积为严寒 3.5%、寒冷 21.4%、温和 45.5%、炎热 29.6%。重复采样稳定性、微小坐标扰动连续性、数值范围、海拔只降温及四档出现检查通过；已查看最终两图。三处样本的山脚／山腰／峰区平均温度为 `5.80 / 4.27 / 1.59`、`6.93 / 5.23 / 1.74`、`6.82 / 5.44 / 2.73`；仍不保证每处山脚与山腰都属于不同类别。

```sh
java -Xmx2g -Djava.awt.headless=true \
  -cp "$(cat neoforge/build/planning-benchmark-classpath.txt)" \
  neoforge/tools/TemperatureFieldPreview.java \
  neoforge/build/planning-r25-final/adventureworldgen/plans/adventureworldgen_default \
  neoforge/build/reports/temperature-organic-v6 32 450 0.012 2.0 110 0.065 0.6 organic 850 1150
python neoforge/tools/audit_temperature_mountains.py \
  neoforge/build/reports/temperature-organic-v6
```

`organic` 模式忽略原先的位置角度参数 32，元数据中 `angle_degrees` 为 null，周期与阶梯过渡宽均为 0。历史两个模式仍保留。输出在 `temperature-organic-v6`，本版仍是实验预览，未替换正式规划器。

## 第七版：减小二维扭曲

根据第六版扭曲过大的反馈，仅将主位移幅度从 850 降至 450 格（减少约 47%），细一级位移幅度随之从 187 降至 99 格。两级噪声尺度、温度场形状参数、基础偏移及海拔降温保持第六版取值，仍使用 `organic` 模式。

```sh
java -Xmx2g -Djava.awt.headless=true \
  -cp "$(cat neoforge/build/planning-benchmark-classpath.txt)" \
  neoforge/tools/TemperatureFieldPreview.java \
  neoforge/build/planning-r25-final/adventureworldgen/plans/adventureworldgen_default \
  neoforge/build/reports/temperature-organic-v7 32 450 0.012 2.0 110 0.065 0.6 organic 450 1150
```

输出保存在 `temperature-organic-v7`，仍为实验预览。
