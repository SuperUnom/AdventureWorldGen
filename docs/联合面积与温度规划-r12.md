# r12：联合面积分配与温度软约束

实现和验证已完成。对应设计见 [群系规划器改造方案](群系规划器改造方案.md)。

## 已接入的流程

1. 海岸生成一次后，按宏观区域的内部可用面积预留出生、必须群系和必须结构承载容量；同一面积只分配一次。选择兼容的区域模板，并为受海拔约束的区域保留侵蚀高度余量。
2. 区域地形、侵蚀和水文生成一次并冻结。后续落位失败不会重新生成或修改这些地形。
3. 建立 16 格位置目录，缓存同一最终 4 格单元的地形和兼容性查询。选中的锚点仍验证原来的精确冒险等级；粗网格没有候选时，按 8 格、4 格细化。
4. 出生点先保留锚点，结构准备实际足迹和保护范围。所有必须群系及完整出生群系的最低面积随后进入同一个配额分配过程。
5. 按离锚点的距离和空间相关噪声排序合法单元，先得到紧凑的初始归属。交替路径可以把先分配的格子转给其他需求，再为原需求补齐替代格子，解决只靠贪心会失败的容量竞争。
6. 面积不足时扩大索引候选域，复用冻结地形和缓存。保留面积上下限、锚点等级、地形及海拔限制；不会通过丢弃需求或放宽等级使规划通过。
7. 填充温度布局使用固定宏观邻接图和有限交换。最终 4 格归属、锚点和宏观容量预留一起保存，加载时恢复同一布局。

## 群系形状与温度

必须地块现在保存稀疏的实际单元集合，形状可以沿合法坡面、谷地扩展；旧版要求整片固定近圆形掩码都能放下的限制已移除。相关噪声尺度为 16/48/128 方块，边缘评分扰动幅度为 72 方块，形成连续起伏及附属斑块，而不是逐格独立随机。

`biomes.terrain_rules.<群系ID>.temperature_level` 为 0～10 的整数，省略为 5；`allowed_terrain` 可省略为全部四种模板。默认配置显式覆盖所有必须及填充群系。它只影响规划，不改变原版温度、雪线或结冰。

必须群系的合法锚点按温度场和确定性种子排序。填充布局在固定的 512 方块陆地邻接图上降低温差平方代价，并把邻近必须地块的温度作为软参考。最多六轮，每个位置每轮尝试十二次交换；只接受代价降低的交换，保留各填充 ID 的陆地种子数量。海洋不计入陆地温度目标，细碎交错边缘不因周长增加受罚。

填充仍不承诺每个 ID 的实际面积或必定出现次数；温度优化保留种子数量不等于保证每种填充群系的最终面积。必须出现的群系应继续列入 `required`。

## 成功保证与限制

面积分配使用整数二部图配额匹配。对于固定锚点及候选域，交替路径可以修复贪心占用；在操作预算内，找到的结果满足全部配额和互斥关系。测试与所有 3×3 兼容图的穷举可行性逐一对照。

宏观预留使用距区域混合边缘留有余量的内部面积；最终成功凭据是冻结地形上的实际格子归属。预留表不会替代侵蚀、水文、适配器和结构准备后的验证。结构仍需要独立验证足迹、入口、保护范围和间距。

**没有把“固定任意种子与配置都必定成功”作为已实现保证。** 硬冒险等级仍然保留，锚点选择、宏观区域容量和结构约束仍可能使某个有限候选域不可行；预算耗尽与域内无解使用不同诊断。宏观容量构造对同时设置上下限的高度区间采用 20 方块侵蚀包络，窄于这个范围时会报告该保守构造域无法满足，并不声称数学上不存在其他地形。

温度不会加入任何硬兼容条件，也不会因冷热相邻抛出规划失败。自然形状、主体连贯及温度接近是软目标。

## 持久化与诊断

- 必须群系保存 `cells_base64` 实际归属及 `anchor_x/anchor_z`；结构承载区域仍保存与冻结结构保护范围一致的掩码。
- 地形保存 `capacity_regions`，重启时恢复相同区域模板和高度余量。
- 计划输入版本为 `planner-v2-impl-2026-09-08-r12-indexed-allocation-v1`，旧实现的缓存不会直接作为新版结果使用。
- 每次从头规划后写入世界目录的 `adventureworldgen/planning-metrics.json`：海岸、容量预留、侵蚀、水文、成本图、索引、结构、面积分配、温度和保存分别计时，附温度代价及阶段检查点观察到的堆占用。
- 耗时不参与随机键、搜索终止或计划字节。READY 缓存加载不计作一次新的冷规划。
- 规划进度条在位置索引建立时持续推进，在结构和面积分配完成时推进。

## 验证

Java 21、Minecraft 1.21.1、NeoForge 21.1.249：79 项单元测试、8 项 Minecraft GameTest 全部通过，`build --offline` 成功。默认配置的旧硬字段与 r11 JAR 中的配置逐项比较一致，新增内容仅为温度元数据。

| `1` | 47.6 秒 | 0.84 秒 | 16.31 秒 | 423680 → 236800 |

验证覆盖全部 27 个必须群系的实际面积与地形兼容、出生区域、必须神殿、原版外海、河岸和递降河流，以及外部适配器。新增单元测试包括全部 512 个三需求三单元兼容图、贪心占用修复、固定锚点、4 格候选、精确掩码与容量信息存储恢复、温度软约束及旧配置兼容。报错种子的 29 块完整地块另已导出审计表。
