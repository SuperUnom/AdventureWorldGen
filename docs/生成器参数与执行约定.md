## 1．参数、版本与确定性

第一版不向作者开放噪声、评分权重、寻路网格和搜索预算字段。内部参数集中为不可变的 `PlannerProfile`，随算法版本发布，调参必须形成新 profile 并保留旧值；不能在搜索失败时悄悄放宽等级、面积、数量或间距限制。

随机键使用 `世界种子／算法版本／阶段名／需求或实例 ID／操作序号` 的 UTF-8 序列，按字段长度前缀编码后做 SHA-256。取摘要前 8 字节为无符号大端整数，最高 53 位除以 `2^53` 得到 `[0,1)` 样本。需要排列时按摘要、再按稳定 ID 排序；不依赖系统时间、容器遍历顺序或共享可变随机流。

位置坐标用方块单位，负坐标的网格索引用向负无穷取整。几何与评分使用严格 binary64 运算语义；超越函数使用平台适配层固定的严格实现，不使用 GPU 近似快速数学。边成本量化为整数微成本；最终比较不靠任意浮点容差放宽作者范围。

同一完整输入、适配器版本集合、profile 与操作预算须复现同一结果。输入数组中的必须群系条目顺序属于输入；其他集合先规范化排序。运行时直接读已保存的计划，不重新抽随机数。

当前版本为 `planner-v2`，采用[粗细地形算法](粗细地形生成算法.md)：16→8 成本网格、连续宏观高度函数、沿边函数采样与有向成本复用。`planner-v1` 的 32→16→8 网格及粗高度插值定义保留在[历史快照](历史版本/planner-v1.md)，不再作为当前输入。未在新版中修改的等级、面积、数量、间距、评分与预算保持原值；细节参数列于下方地形 profile。计划负载升级为 [plan-v2](运行时与结构适配.md#persistence)，旧格式见[历史快照](历史版本/plan-v1.md)。

## 2．面积与最终群系归属

### 2.1 单位与表示

面积的单位、默认值和输入宽度规则见[公共 area](配置说明.md#area)。本节定义其内部表示：最终边长为 4 方块，有效范围按单元面积 16 向内量化。

```text
n_min = ceil(area.min / 16)
n_max = floor(area.max / 16)
16 n_min ≤ 最终面积 ≤ 16 n_max
```

**交集后的范围不再次要求宽度至少为 256。** 多个合法输入取交集后可以较窄，只要含有可表达的面积即可；否则该共用关系在当前表示下不可行，可拆分需求，不直接断言整个配置矛盾。

最终平面归属由边长 4 方块的格子组成，格子为 `[4i,4i+4)×[4j,4j+4)`，查询样本为中心 `(4i+2,4j+2)`。每个格子保存唯一 `patch_id`，每片必须地块的面积严格为所属格子数乘 16。相同群系 ID 的相邻地块不合并；内陆河流和湖泊不从所在群系的水平投影面积中扣除。

必须地块及结构保护格子要求整个 `4×4` 水平单元处在大陆轮廓内，不接受只在角点相接或跨出海岸的单元。剩余沿海单元按中心相对同一海岸折线的侧别选择填充群系或外围海洋；海岸地形高度仍查询原折线，这种群系采样量化不重新移动地形岸线。生物群系身份是平面归属，地表和地下沿用该平面 ID；第一版不做垂直群系分层。

最终归属表示即运行时群系查询的依据；不再叠加一个改变归属的噪声步骤。若目标运行时不能复现此采样约定，该适配器不能宣称支持本版面积契约。

### 2.2 分配精度

先在 `16×16` 单元上共同分配最低面积，失败后允许按 `8×8 → 4×4` 两级细化重新搜索。每个粗单元由完整的最终 4 格子组成，所有子格都合法时才可作为必须地块候选。临海、障碍附近被粗单元排除的位置可在后续细级重新进入候选。

每一级都按其实际单元面积向内换算范围，不四舍五入放宽。某一级换算为空或连通域不足仅说明该级不适用；最终 4 格子域、位置与承载选择都未穷尽时不能宣称无解。成本网格与群系分配网格独立，细分归属本身不触发成本重算。

| 出生中心范围 | 玩家水平坐标距 `(0,0)` 不超过 `r_spawn=min(256,R/10)` |

中心保留圆 `r_keep = r_spawn + footprint_radius + margin`，其中 `footprint_radius` 是全部出生合法旋转下、以相对出生点为中心覆盖结构占地与保护范围的最大水平距离；仅群系出生时为 0。`margin=min(32,R/20)`。若 `r_keep ≥ R/2`，或最终折线距离原点不足 `r_keep`，第一版报告当前半径与出生预留不兼容，不自动缩小建筑、减少预留或修改海岸场。作者可以更换出生结构或扩大半径。

海岸样本直接以岸线为终点，从陆侧执行[成本查询契约](#cost-model)的合法短连接；只允许线段终点接触外海边界，不使用任意偏移点替代。可达样本成本排序，偶数个样本时取中间两项算术平均；以该值建立共同等级区间。没有可达样本或参考不大于零，放弃当前出生与粗地形方案。

外海方块量化统一规定 `S` 为顶层水方块的整数 y，水体物理上表面为 `H_sea=S+1`。连续地面高度 `H` 表示地面上表面，顶层实心块 y 为 `floor(H)-1`。干陆侧取至少 `S`，外海侧取至多 `S-1`，再在海床以上填水至 `S`；如此不会因小幅正负高度取整而在海岸两侧混淆水陆。内陆水体是显式例外，使用自己的水面和床面。此为本项目的坐标契约，适配器须转换宿主引擎的水位参数。

河口沿河网的最后一段与既定折线相交处接入海洋，沿程检查地面与两岸高度，经反向坡度约束和正向非递增约束把水面接到 `H_sea`，同时保持沿下游水面不升高、中心床面低于水面至少 2 方块，浅岸允许小于 2 方块并连续填水；较短末段使用实际长度。若粗河网无法同时满足这些条件，拒绝该河网候选，不改写外海轮廓。水体系统必须在成本图建立前提交河口与主要水面。

## 4．粗地形、通行成本与查询

### 4.1 网格与表示

成本图初始网格间距为 16 方块，原点对齐世界 `(0,0)`，按 `16 → 8` 细分；大陆掩膜四邻接检查失败，或当前成本精度下全部候选阶段仍未找到合法方案且预算尚存时进入下一精度。每个节点保存粗地面高度、水面高度、水体类别和危险／不可通行标记。陆地连通检查在叠加内陆水体前进行，不把水面连通当作陆地可达。

节点高度通过同版本 `macroHeight(x,z)` 精确查询并缓存。连接中间位置直接查询同一连续宏观函数及水体／危险几何，不用两端净高差或粗节点双线性插值代替。函数查询不回读最终方块或局部细节噪声；这里的精细计算指沿宏观地形函数分段累计，未增加玩家精细通路验证。缺少可查询的宏观函数或必要水体边界时，该地形源不能宣称满足本契约。

### 4.2 路段成本

使用水平长度；八邻接的正交、对角连接长度分别为 `g` 和 `sqrt(2)g`。对规范端点顺序的一条连接，设水平长度为 ℓ，取 `m=ceil(ℓ/8)`，在 `p_i=u+(i/m)(v-u)` 处直接查询宏观函数。补入线段与水体、危险和海岸边界的交点，按参数位置排序去重，因此每个微段长度不超过 8。16 格正交边至少分为两段，对角边至少分为三段；增加边界点后可更多。沿同一组位置采样得到的高度序列计算正反两个方向，不只用起终点净高差。对微段：

```text
s = (h_next - h_current) / horizontal_length
F(s) = 1 + 4 max(s,0) + 2 max(-s,0) + 6 s²
segment_cost = horizontal_length · F(s) · water_multiplier
```

干地使用粗地面高度；浅水、深水段使用粗水面作为通行面。上坡与下坡分别计算，始终非负。任一微段 `|s| > 2` 不建立连接；这是宏观陡坡截止，不是玩家逐方块攀爬能力模拟。

| 地表条件 | 通行规则 |
|---|---|
| 干地 | 倍率 1 |
| 内陆淡水，粗水深 `0 < depth ≤ 1.5` | 涉水，倍率 2 |
| 更深的内陆淡水 | 游泳，倍率 5；第一版不计船、药水、装备与流速 |
| 熔岩、适配器标记的危险区域、外海 | 不通行；外海岸线只允许作为海岸查询的终点 |

水深取粗水面减粗床面，微段接触多个类别时使用最高倍率；危险类别优先。方向性只由坡度产生。具体水体边界穿越点也用于分段，避免仅因固定采样点未命中而漏过窄水体。

反向遍历同一组采样位置时，各微段坡度变为 `-s`，水体倍率沿用同一几何分类；正反方向分别按公式累计，不能把一个方向的成本直接复制到另一个方向。当前坡度阈值、水体与危险规则在反向时可通行性对称，但费用不对称；两个方向仍分别保存状态。

一条图连接的各微段成本求和后，乘 `10^6` 并按最近偶数舍入到 64 位整数；非零长度连接最小为 1 微成本。溢出或非有限高度报告输入／资源错误，不产生负权；Dijkstra 与海岸中位数统一使用这一单位。出生原点的查询值严格为 0。

### 4.3 防止穿障碍与非网格查询

连接检查覆盖线段穿过的所有粗网格单元，并做线段与海岸／粗水体／危险边界的相交检查。对角 `u→v` 仅在两条途经旁侧节点的正交折线 `u→a→v`、`u→b→v` 在同方向均可通行，且对角本身通过微段检查时建立；不会从两个障碍角之间穿过去。正交辅助检查不递归检查对角。

对非网格位置 `p`，查询包含它的网格面向外一圈节点，即索引范围 `{floor(x/g)-1,...,floor(x/g)+2}` 与 z 的笛卡尔积，最多 16 个。逐一检查真实短连接，取 `C(v)+w(v,p)` 最小值；不扩大到任意远点凑出可达结果。没有合法接入返回无穷大。

出生点作为额外源节点，用同一邻域和连接规则建立 `p_spawn→v`；普通查询使用 `v→p`，有向代价不能反过来用。入口即使有合法结构内部通道，仍按其入口投影和适配器提供的地面接入高度评估；地下整座建筑不额外参与路线规划。

<a id="dijkstra"></a>

### 4.4 单源求解与查询复用

按上述规则提供可按需查询的有向图，出生位置作为额外源节点。只计算成本图时无需保存路线前驱，也不构建全点对距离矩阵。堆中按成本与稳定节点 ID 排序，只在距离严格降低时入堆：

```text
C(出生点) = 0；其余节点 C = 无穷大
settled(所有节点) = false
将 (0, 出生点) 加入二叉最小堆
while 堆非空:
    (d, u) = 弹出最低成本条目
    if d != C(u) or settled(u): continue
    settled(u) = true
    for 每个候选邻点 v:
        if settled(v): continue
        edge = 查询已检查的有向连接(u,v)  # 见边缓存
        if edge 为 BLOCKED: continue
        candidate = checked_add(d, edge.cost)  # 检查整数溢出
        if candidate < C(v):
            C(v) = candidate
            将 (candidate, v) 入堆
```

在固定图上，每个可达节点只展开一次，每条出向连接最多进行一次上述松弛；过期堆条目不重新查询边。持续到堆为空，不在某个目标处提前结束；不可达节点保持无穷大。N 个粗网格节点的 Dijkstra 时间为 `O(N log N)`、内存为 `O(N)`，另计按需边采样与几何查询开销。每边采样数受长度和边界交点数影响，不能把全部生成成本都算作固定一次堆操作。

<a id="edge-cache"></a>

### 4.5 边成本的计算、复用与失效

仅就上述 Dijkstra 松弛过程，不需要为了防止过期条目而预先计算全图边权。但是本项目的反向费用、对角双绕角检查及同地形版本更换出生候选，会重复需要同一物理线段。当前采用**按需建立的相邻节点对缓存**：第一次请求时查询高度函数，一次计算正反方向的成本；后续直接读取，不提前计算不可达区域的所有边。

缓存键为 `(terrain_version, cost_profile_version, grid_origin, grid_spacing, min(node_id), max(node_id))`。`terrain_version` 包含区域与模板参数、海岸、水体、危险边界、噪声内核及已提交支撑补丁；正反方向以规范节点顺序存储，返回时按请求方向选择。不得跨版本或将端点接入高度不同的线段误作同一键。

分两层保存结果：

1. **线段结果**：该线段自身的几何通行状态和两个方向的整数成本。由规范方向的同一采样序列产生，采样完可以释放中间数组。
2. **图连接结果**：正交边直接使用线段结果；对角边再查询四条正交辅助边，两个方向分别检查两条绕角路线，并结合对角线段自身结果决定可通行性。辅助检查只查询正交边，不递归检查对角，也不把绕角路线成本加到对角费用里。

每层区分 `UNCOMPUTED`、`READY`、`BLOCKED`，不可达结果也保存，避免对失败线段重复查询。单个地形／网格版本的活动缓存不驱逐；并行首次请求应合并为一次计算，其他请求等待已完整发布的结果。网格使用每节点四个规范方向槽位表示无序邻接对，每对保存双向值及必要状态，合计 O(N) 存储。整图估算时连同缓存、距离、settled 和堆一起计入 1 GiB 工作内存限制，超限按资源限制报告，不悄悄换精度。

更换出生位置但宏观地形未变：保留普通网格边缓存，重建源点短连接和 Dijkstra 距离图。整平、河网、水面、海岸或宏观函数改变：切换版本，重新计算该版本需要的边、整张成本图及等级区间；旧版本结果不能用于新图。回退时只有完整版本键一致才可复用旧缓存，多版本同时驻留也计入资源上限。

非网格入口与海岸样本也走同一沿线函数采样规则。其短连接可在查询批次内按精确端点、接入高度与地形版本复用；对完整 `C(p)` 的缓存还须包含出生源点和成本图版本。已查询的邻域结果可在有界批次缓存中复用，内存不足时释放该批次并允许以后重算。短连接不要强制塞进规则网格边槽，也不因两个位置恰好落在同一格而共用费用。缓存是派生数据，不写入持久化计划；重建或重算必须产生相同费用。

以下无水、可通行算例用于检查费用计算。水平端点为 x=0 和 x=16，中间采样 x=8；表内是乘 `10^6` 前的成本单位：

| 高度序列 h(0), h(8), h(16) | 正向成本 | 反向成本 | 应排除的错误 |
|---|---:|---:|---|
| 0, 0, 0 | 16 | 16 | 基础路程不能为零 |
| 0, 4, 0 | 64 | 64 | 两端等高不代表平路；中间凸起必须计入 |
| 0, 4, 8 | 72 | 56 | 上下坡费用不同，不能复制反向成本 |

验收至少记录地形函数调用次数、线段结果首次计算次数与缓存命中数；固定活动版本内同一相邻对的高度采样最多执行一次，对角辅助查询与后续 Dijkstra 查询共享该结果。

## 5．地形修复边界

第一版关闭通用的“降低山口、开辟新通路、搬移山脉、改海岸”搜索修复，不把它作为求解成功的前提。搜索失败采用扩大候选、精度细化和更换出生候选；后续版本再添加宏观修复算子。

第一版只允许为出生及已准备结构做适配器明确要求的局部支撑整平，并在建立该地形版本的成本图前提交：目标高程为支撑面粗高度中位数，每点最多升降 8 方块，保护范围外最多 16 方块平滑衰减；不得改外海、水面、既有保护范围或产生占地冲突。需要超过 8 方块的修改则该候选不可用。修改由候选提交，撤销候选同时撤销修改。

出生整平在第一次 Dijkstra 前完成。其他结构的候选若要求整平，在联合搜索中用独立地形版本暂存，整图重算并更新海岸参考、全部等级区间和已有对象合法性；同一出生／候选阶段最多提交 4 个不同整平版本，每次提交在任何受影响候选继续使用前失效并重建其成本、等级与兼容域，超出是预算耗尽，不是配置冲突。相同整平补丁摘要不重复提交或循环震荡。

最终细节只允许在出生与结构预留范围内一次恢复已批准的支撑面并衰减细节；它不得改变已批准的粗地形版本。细节引入的其他局部通行误差仍被忽略。任何主动粗地形修改均必须重算成本；只改群系标签不用重算。

## 6．候选、评分、间距与预算

### 6.1 候选域

群系种子候选为当前分配格子的中心。结构原点水平步长依次为 32、16、8、4 方块，世界原点对齐；高度按适配契约，不扫描任意 y。出生候选步长为 16、8、4。联合候选阶段依次使用 `(分配步长, 结构步长, 出生步长) = (16,32,16), (8,16,8), (4,8,4), (4,4,4)`，后级重建并保留合法旧候选，前级失败不代表后级失败。

每个需求初期保留最多 256 个候选，按其等级区间内 8 个成本小段和水平 8×8 分区轮流取样，同桶按种子键排序；后续上限为 1024、4096，最后遍历本阶段完整有限域。候选原始枚举也计入预算，不能为了宣称“完整”绕过资源限制。

最少候选优先保持不变。候选分数从小到大尝试，定义所有归一化项限制到 `[0,1]`：

```text
S_candidate = 1.0 · level_error + 1.5 · lost_domain_ratio
              + 1.0 · space_pressure + 0.5 · proximity + 0.1 · noise
level_error = |C(p)-T_L| / (εΔ)
```

`lost_domain_ratio` 是本次传播删除的其他未决候选比例；空分母取 0。`space_pressure` 取受影响地块中 `D/max(U,a)` 的最大值，U、D 见[范围调度](#shape-profile)。`proximity` 是候选入口与已放入口的最大高斯接近惩罚，σ 使用散落定义；没有其他入口取 0。同分按稳定 ID 和坐标排序。评分不剪掉合法分支。

### 6.2 最小与最大间距

作者间距字段的完整含义见[spacing](配置说明.md#spacing)。实现按同 ID 入口的水平距离检查：`min` 为任意两座下界；`max` 通过阈值图连通性检查，等价于最小生成树最长边受限。0 或 1 个实例自然满足。

部分搜索只用 `min` 和可证明安全的容量检查剪枝，`max` 连通性在完整同 ID 实例组上判定，不能因为当前部分图断开就提前拒绝。

启用 `max` 后，更多实例可能连接两个分离区域。因此“恰好下界数量放不下”不再足以判定范围内无解：先尝试有效下界数量，再按总额外实例数递增、结构 ID 稳定次序枚举范围内数量向量，全部计入必需搜索预算。获得任意范围内合法方案即进入可选增量；每次可选增加也须保持连通。其他条目同样优先下界；只有能证明删除额外实例仍可满足包括填充在内的全部约束时，才可省略其更高数量分支。比如额外结构新建的承载地块可能覆盖填充池不兼容的地形，不能无条件假定删除实例后仍有解。数量向量未穷尽且无等价性证明时不得返回 `NO_SOLUTION_IN_DOMAIN`。

### 6.3 操作预算与资源上限

| 项目 | `planner-v2` 上限 |
|---|---:|
| 一个粗地形方案的成本节点 | 2,000,000 |

| 全次必需面积分配状态展开 | 1,000,000 |
| 可选增加尝试 | 128 次；单次最多 2,000 个联合状态、10,000 个面积状态 |
| 可选增加总预算 | 40,000 个联合状态、200,000 个面积状态 |

一次状态展开、候选 prepare、边界修改尝试或洪泛单元访问各自计一次；无效尝试也计数。计数器跨候选、数量向量、出生方案和精度阶段累计，不在内层重置。可选／优化耗尽保留合法解并仍做完整检查；未找到合法解或最终检查未完成则不能返回成功。

节点数或内存超出返回 `RESOURCE_LIMIT`，含估算和限制；操作预算耗尽返回 `SEARCH_BUDGET_EXHAUSTED`。主算法既有无解分类保留，`UNSUPPORTED_CONTENT` 用于缺少适配能力。诊断至少包含配置 JSON 路径、实例／地块、数量向量、候选域与精度、地形版本、成本区间、面积交集、空间瓶颈、计数器及明确原因。

可使用位集表示候选兼容关系、撤销日志保存搜索变化、空间哈希查询占地；不建立全世界所有点两两兼容的稠密矩阵。这些选择不改变穷尽范围和失败语义。

## 7．群系范围调度、形状与边界

### 7.1 紧张程度与格子顺序

对地块 b，`X` 是当前取得的格子、`Rb` 是保护目标。U 为从 X 可达、尚可取得的合法空闲单元总面积，不包括其他地块当前占用或独占预留。D 取以下三个下界的最大值：最低面积缺口、尚未纳入保护单元的面积、到最远未纳入保护目标的最短连接所需新增面积。第三项按四邻接合法域的最短路径计算；到任一目标无路则该分支失败。使用最大值避免把重叠需求相加后误剪枝。

优先选择 `(U-D)/max(D,a)` 最小且尚未满足最低需求／保护目标的地块，a 为当前单元面积。`U<D` 可剪枝，但 U 足够只说明必要条件通过。并列按未连接保护面积较大、再按稳定 ID 排序。洪泛与最短连接检查计入访问预算；不把预算耗尽伪装成空间不足。

候选格子次序使用：

```text
S_cell = 0.45 · distance + 0.30 · perimeter + 0.15 · terrain + 0.10 · noise
distance = min(1, 平面距种子 / sqrt(A_max/π))
perimeter = (加入该单元造成的周长变化 / (4·单元边长) + 1) / 2
```

`terrain∈[0,1]` 由群系适配器给出软偏好，没有偏好时统一为 0；硬地形条件仍先过滤。`noise∈[0,1]` 使用 256 方块格距的种子哈希值噪声，双轴采用 `t²(3-2t)` 平滑插值。它仅改变分支顺序，不能越过保护范围。

### 7.2 额外面积

最低需求及可选结构确定后，设每片地块软目标为当前有效面积区间中点，向下量化到本阶段单元；低于现有面积时取现有面积。按 `当前面积/软目标` 最小的地块轮流增加一个合法边界单元，并继续使用 `S_cell` 排序；并列按稳定 ID。

目标仅用于调度，不是新硬约束。单轮所有地块都无合法增长、都到软目标或预算耗尽即停止，保留较小合法范围。这样不会为了追求上界耗尽全部填充空间，也不在最低需求搜索前固定随机目标。

### 7.3 细化与边界交换

取得当前精度的可行解后，将归属无损细分到最终 4 格子，再处理填充与边界。细分不加入独立边界噪声。依次尝试单格转让、相邻两片之间的一对格子交换；只有总形状能量严格下降且所有硬约束继续成立才接受。种子格和结构保护格不可转让，海岸之外格子不可进入必须地块。

移除单元前检查供体四邻接连通，加入后检查受体共边连接；拓扑不明确时对受影响地块洪泛。同时复查面积、地形、种子归属及保护范围，失败整次回滚，不能只回滚一个格子。

形状能量定义为各必须地块的 `0.45·平均 distance + 0.30·min(1, perimeter/(4·格子数·4)) + 0.15·平均 terrain + 0.10·平均 noise` 之和；固定种子和面积范围，所有均值按当前单元集合计算。填充地块不纳入这个能量，也不取得必须地块面积名额。该能量只用于已可行解修整，不替代最低面积搜索。

跨对象位置优化仍可移动种子或结构，但须重新求解受影响归属并检查成本和间距。最终 4 格子边界已经是第一版最终表示，保留这个粒度的形状，不另做逐方块美化。

<a id="scatter-profile"></a>

## 8．共同散落布局

所有 `scattered` 实例（含固定出生实例）共同计算评分。n 是当前实例总数，A 是当前候选入口联合合法域的面积估计：世界对齐 32 格点中合法位置数乘 `32²`，再限制到大陆面积以内。取 `σ=max(32,0.5 sqrt(A/max(n,1)))`。

从上述合法格点按种子哈希取最多 2048 个不同位置为 Q。完整一次优化中固定 A、σ、Q 与归一化尺度；接受结构增量或改变粗地形后再开启新的优化阶段并重新建立它们。

```text
E_close = mean(i<j) exp(-||pi-pj||²/(2σ²))
E_empty = mean(q∈Q) min_i ||q-pi||² / (4R²)
E_scatter = 0.6 E_close + 0.4 E_empty
```

n 小于 2 时接近项为 0；n 为 0 时跳过整个优化，Q 为空时空缺项为 0 并记录。低频扰动只以 0.1 权重进入候选排序，不在优化后直接挪坐标。轮流尝试移动结构候选、交换两实例候选、移动群系种子、调整兼容承载关系；硬约束全部通过且 `E_scatter` 严格下降才接受。同分不接受，避免循环。

`spacing.min/max` 是同 ID 硬约束；本节是跨 ID 软目标，两者同时执行。第一版没有独立密度字段，数量由 `count` 控制。

## 9．填充群系

`biomes.filler` 是必填非空的 ID 字符串列表，规范化时去重并按 ID 排序；相同 ID 重复书写不增加权重。第一版不配置填充等级、权重、面积范围，也不保证各 ID 必须出现。

对最终 4 格子中未归属的大陆填充域做四邻接分量划分。世界对齐的每个 `256×256` 分区，从其空闲单元中取种子哈希最小的一个作为填充种子；没有种子的独立分量补一个哈希最小的合法格子。

对每个种子筛选当前可兼容的填充群系，按种子哈希从排序后的合法列表等概率选一个，要求种子位置符合该群系地形能力。使用四邻接多源扩张，边权 `4·(1+0.25·noise)`，只在未归属的填充域内竞争，并保持群系能力限制；同成本按种子稳定 ID。噪声使用[范围调度](#shape-profile)的值噪声与独立阶段键。

若某群系扩张被硬地形限制挡住，余下未覆盖分量重新补种子继续；每轮至少占领一个单元，整个过程受单元访问预算约束。某个大陆单元不被列表中任何群系支持时返回填充兼容性失败，不能回退成未配置群系。默认通用群系适配器可接受全部普通大陆地形，专门适配器才添加具体限制。

填充种子不参加冒险等级排序，填充面积不纳入必须地块统计。r8 在河湖上叠加原版 `minecraft:river`，默认寒冷群系使用 `minecraft:frozen_river`；底层承载归属仍用于面积统计。两个水域群系纳入预检，外围海洋固定使用 `minecraft:ocean`，由运行时适配器解析并记录，未解析到则不启动生成。填充算法与海岸范围分工明确，不能用填充扩张覆盖外海。

- 地形模板对宏观高度的混合权重不变。`MacroSample.terrainTemplate` 在混合坡面按这组权重和相关噪声作斑块式选择；`regionId` 仍报告最近的宏观区域。地形内部只有一个非零模板权重时，身份保持不变。
- 填充群系先遵守地形及高度硬限制，再使用距离差 160 格的竞争范围与平方衰减权重。世界坐标上的相关阈值决定实际斑块归属，20/60/160 格三层分别形成局部斑块、聚集和较大弯曲。
- 本节替代前述最终过渡带必须四邻接单连通的旧设计；过渡带允许离散附属斑块与邻居嵌入，所有归属单元计入同一面积。
- 必须地块使用同一份冻结边框内的核心与斑块过渡蒙版。过渡半宽为半径的最多 0.24，最多 40 格，并受边框余量限制；噪声尺度为 12/36/96 格。`contains`、面积计数、冲突检查、结构保护和运行时查询共同使用该蒙版。
- 高度上下限的填充过渡位于允许侧 12 格高度范围，所有输出仍满足硬上下限。河流、湖泊覆盖和海岸几何不在本次修改范围。

## r11：成本细化与出生区域预留

- 局部 8 格成本图覆盖 256 方块的方形窗口，各轴起点为 `floorDiv(坐标+128,256)*256-128`。查询坐标必须在选中的窗口内，负坐标使用同样的向下整除规则。
- 窗口内所有重合的 16 格节点以及窗口周界导入全局已求解成本，作为局部 Dijkstra 的初始上界。不能只从周界导入，否则会给内部出生点添加虚假的往返成本。
- 出生群系首先保留完整合法掩码。居中位置不满足地形限制时，在 `min(256,R/10)` 的中心域内按 16 格、4 格两级尝试平移掩码；必须继续覆盖原点，实际面积和所有归属单元的地形限制不变。玩家出生点及成本源仍为原点。之后安排必须结构承载区，再安排其余必须群系；普通群系仍保留原需求序号作为候选随机键。
- 详细复现和验证见 [r11 规划崩溃修复](规划崩溃修复-r11.md)。
