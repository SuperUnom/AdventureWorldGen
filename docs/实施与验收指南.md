## 2．按依赖实施

| 顺序 | 实施单元 | 前置输入与主要产物 | 规则入口 | 应提交的验证证据 |
|---|---|---|---|---|
| 1 | 配置与数据表示 | JSON → 规范化需求、稳定需求／实例／地块 ID；建立 profile 和网格表示 | [配置](配置说明.md)、[确定性](生成器参数与执行约定.md#profile)、[归属](生成器参数与执行约定.md#area-grid) | 必填与默认、重复与未知字段、数量和面积边界、负坐标与量化 |
| 2 | 适配能力与受控粗地形输入 | 注册内容与适配能力 → 可查询粗地形、可预先准备的完整结构；测试输入显式标明用途 | [结构适配](运行时与结构适配.md#spawn-adapter)、[粗地形契约](生成器参数与执行约定.md#cost-model) | 不支持内容能提前失败；原点、旋转、物理占地和保护范围分别验证 |
| 3 | 海岸、区域模板与出生候选 | 半径、种子与出生预留 → 固定区域、宏观函数、粗采样和安全位置 | [海岸算法](海岸轮廓生成算法.md)、[粗细地形](粗细地形生成算法.md)、[出生安全](运行时与结构适配.md#spawn-adapter) | 区域边界、丘陵高差、采样一致性、轮廓与出生检查 |
| 4 | 成本图与等级 | 固定出生及粗地形 → 有向成本、合法短连接、海岸参考与共同区间 | [成本模型](生成器参数与执行约定.md#cost-model)、[等级](群系种子与结构位置选择算法.md#level-cost) | 边内凸起、双向代价、缓存调用计数、防穿障碍、非网格接入及失效重算 |
| 5 | 联合搜索与最低面积 | 候选、适配数据与等级 → 数量向量、承载关系、位置和实际空间分配 | [承载](群系种子与结构位置选择算法.md#carrier)、[搜索](群系种子与结构位置选择算法.md#search)、[最低面积](群系种子与结构位置选择算法.md#minimum-area) | 局部争地回退、交集拆分、独立地块计数、最大间距所需额外实例 |
| 6 | 优化、填充与独立检查 | 可行布局 → 最终 4 格子归属与已检查计划 | [优化](群系种子与结构位置选择算法.md#optimization)、[填充](生成器参数与执行约定.md#filler)、[最终检查](群系种子与结构位置选择算法.md#validation) | 优化失败回滚、填充兼容、硬约束复查、预算耗尽保留合法结果 |
| 7 | 计划发布与 Minecraft 接入 | 已检查计划与实际适配器 → 持久快照和真实区块 | [保存与执行](运行时与结构适配.md#persistence) | 原子发布、读取校验、重复回调与事务重试、受控 ID 禁止计划外生成 |
| 8 | 完整地形与内容验收 | 明确选定的地形／河网方案、真实内容 → 完整冒险大陆 | [剩余水体与海床边界](生成流程候选.md#terrain-candidate)、下节验收矩阵 | 实际出生、岸带、水体、原版及第三方结构和群系表现、性能记录 |

前六步可使用受控的粗地形和适配测试输入验证规划逻辑；这不能替代真实 Minecraft 适配。完整地形接入前需明确外围选型，不能把外部手册全部默认采用。测试输入、已实现接口和生产实现应在交付说明中清楚区分。

## 3．实施前快速核对

以下是容易在局部修改中遗漏的跨阶段规则；完整定义以链接为准。

| 编号 | 必须保持的规则 | 定义位置 |
|---|---|---|
| I-01 | 出生位置先于成本图固定；粗地形变更后整图更新并复查全部对象 | [失效依赖](生成流程候选.md#cost-recalculation) |
| I-02 | 种子和入口共享等级区间；跨度有意义，不能替换为欧氏半径或分别排序 | [共同等级](群系种子与结构位置选择算法.md#level-cost) |
| I-03 | 显式必须群系每条独立一片；同 ID 填充不计入必须面积 | [群系配置](配置说明.md#required-biomes)、[最终表示](生成器参数与执行约定.md#area-grid) |
| I-04 | 承载共用取交集，失败可拆分；空间失败须能回退位置与关系 | [承载关系](群系种子与结构位置选择算法.md#carrier)、[面积分配](群系种子与结构位置选择算法.md#minimum-area) |
| I-05 | 数量按全存档 ID，出生计入一次；数量下界失败不能漏搜必要数量分支 | [数量](配置说明.md#structure-count)、[数量向量](生成器参数与执行约定.md#search-profile) |
| I-06 | 面积向内量化，四邻接归属；物理占地与群系保护范围分开 | [面积表示](生成器参数与执行约定.md#area-grid)、[适配](运行时与结构适配.md#spawn-adapter) |
| I-07 | 评分只是软目标，不能放宽硬约束；最终检查有独立预算 | [预算](生成器参数与执行约定.md#search-profile)、[终止](群系种子与结构位置选择算法.md#termination) |
| I-08 | 规划与运行时共享海岸、归属和实例计划；按部件幂等执行 | [保存执行](运行时与结构适配.md#persistence) |
| I-09 | 不增加精细路线、首次接触顺序或细化通行反馈检查 | [项目边界](设计原则.md#goal) |
| I-10 | 粗细阶段共享区域与宏观函数；边内直接采样函数，同版本相邻对复用双向费用 | [地形算法](粗细地形生成算法.md)、[边缓存](生成器参数与执行约定.md#edge-cache) |

## 4．验收矩阵

下表是应完成的验收要求，不是已通过的测试结果。验证实现行为，不以参数写入文档、ID 能解析或构建成功替代功能证据。

| 类别 | 必须覆盖 | 可评审证据 |
|---|---|---|
| 配置 | 必填与缺省、未知／重复键、重复 ID、出生引用、面积交集、间距和数量矛盾 | 输入与预期结果，失败指向具体 JSON 路径 |
| 海岸 | 固定种子、0/2π 接缝、圆形基准、包络与中心保留、折线误差、粗网格孤格／海湾封口、等弧长样本、无可达海岸 | 几何与掩膜检查；岸带量化和实际陆海一致性。细项见[海岸验收](海岸轮廓生成算法.md#acceptance) |
| 粗细地形 | 固定区域与模板；区域边界和三交点；丘陵主要高差；粗采样与同坐标函数一致；细节幅度、保护与区块接缝 | 同种子高度样本、不同采样精度及区块顺序对比；不以粗网格插值代替原函数 |
| 成本与等级 | 端点等高中间凸起、正反上下坡、窄水体交点、防穿障碍、非网格查询、海岸中位数与等级区间 | 函数输入与预期费用；包括正交、对角和非网格短连接 |
| 边缓存与失效 | 相邻对一次采样得到双向值；重复堆条目不重复展开；对角辅助检查共用正交结果；仅换出生复用网格边、地形修改后重算 | 缓存与无缓存结果一致；相邻对首次计算次数、函数调用数和命中数；无过期版本读入 |
| 联合编排 | 数量、面积和四邻接；保护范围与占地；共用拆分；重复必须条目和同 ID 填充独立；最大间距需增加中间实例 | 合法解约束报告及会触发回退的场景；不只检查总面积 |
| 优化与填充 | 可选增加、额外面积与散落修改后保持硬约束；最终表示一致；填充不兼容明确失败 | 修改前后检查，失败回滚，最终归属与面积统计 |
| 确定性与资源 | 完整输入、版本、profile、预算相同则结果相同；计数跨阶段累计；资源提前估算 | 重复结果对比、版本记录、操作计数和内存估算；性能数据单独记录 |
| 失败语义 | 抽样失败、精度不足、预算耗尽、资源限制、适配缺失与已证明域内无解分别处理 | 诊断含数量向量、候选域、地形版本、区间、空间瓶颈和计数器；未完成最终检查不得成功 |
| 保存与运行 | 不同区块顺序、卸载／重载、重复回调与事务重试保持布局及数量；实际出生准确；抑制原生额外生成 | 发布与重载检查、真实区块记录；至少一种原版结构和一种第三方结构验证 |
| 群系兼容 | 注册解析、最终归属和面积一致，真实表层／植被／水体表现 | 实际区块检查与所用模组／适配版本；只解析 ID 不算兼容 |

源码检查、自动化测试、构建验证、性能评估与游戏验收分别记录。尚未测试的部分保留明确状态；内部默认值是实现基线，调参按新 profile 发布，不倒推旧规则已被实测证明。

## 5．实施任务的交付信息

每次交付应让下一位开发者或 AI 能直接接续：说明实现了哪个单元及其定义链接、实际修改了什么、使用了什么版本与输入、验证了哪些行为、哪些仍未验证。涉及失败时给出可复现输入和具体诊断，涉及外围候选时说明选型状态。

更新本页状态应有相应源码和验证证据。外部参考的数值、接口或建议只有经本项目明确选用后，才进入对应规范；不根据文件长度或措辞强度推断设计优先级。
