# r16：需求温度带与竞争生长

后续四温度类别、持续生长、默认填充与存档恢复改动见 [r17](四温度带与存档直读-r17.md)。本文保留 r16 历史结果。

实现版本：`planner-v2-impl-2026-09-08-r16-demand-climate-growth-v1`。本页取代 r12～r14 关于“只分配最低面积”“规划层混合斑块”“标签交换优化温度”的实现描述。作者字段以[配置说明](配置说明.md#required-biomes)为准。

## 流程与实现

1. 原有大陆、区域地形、侵蚀和水文先冻结。`PlacementIndex` 共用最终地形样本；只允许干燥合法陆地参与必要面积。
2. `ClimatePlan` 以目标面积统计温度需求；多类型按偏好与对应合法土地供给的平方根归一分配，合计保持一份目标面积。填充池贡献基础比例。32 方块环境网格排除水域；局部高度、96 方块坡面高度和 256 方块山体高度按 25%／55%／20% 组合，海拔降温系数为每格高度 0.0048 个原始温度单位，避免只按平面坐标分带。连续坐标扭曲、地形起伏调制噪声共同改变边界，再校准连续温度场阈值，比较 8 个大尺度趋势方向的合法地形供给，允许有限局部边界修正。出生温度核心优先固定。
3. `BiomeAllocationPlanner` 按出生、等级升序、同级目标面积降序选址。评分结合连续温度、高度偏好、合法空间探测、等级偏差、面积相关间距和稳定的加权随机抽样。
4. 必要群系在 4 方块网格竞争扩张。只入队活跃四邻接边缘，不预建全域“群系×地块”候选图。全局优先队列调度各群系边缘，最低面积缺口获得高奖励，接近目标后降低优先度。累计坡度路径、连续方向扭曲、邻接支持决定形状。
5. 最低面积完成后，在附近剩余空间加入不同间距的填充种子，与必要群系共同竞争。实际填充归属以 `filler/*` 掩码冻结；不把其面积当作必要配额。过小的填充种子残留留给补全阶段处理。
6. `FillerLayout` 从已有填充边缘继续，在剩余大块区域以变化间距播种，选择结合环境、等级、填充权重和附近同 ID 覆盖量。16 方块网格完成多源扩张，硬限制隔开的剩余空间另起合法种子。两次有限局部整理移除单格孔洞、突出；查询时的小尺度连续坐标扭曲避免整齐网格线，候选仍检查当前位置硬规则。
7. `LocalBiomeBlend` 独立执行默认 4 方块半径的查询扰动；位移的欧氏距离不超过半径，读取原始归属，因此不会递归、不会引入远方群系，查询顺序不参与结果。地表使用相同 Minecraft 群系查询结果，不单独混合材料或植被。
8. 必要群系混合后按实际干燥 quart 查询统计。若低于最低面积，只关闭受影响地块的混合；出生核心及结构保护范围保持稳定。最终验证失败禁止发布 READY。固定计划编解码后需逐点复现查询。

## 预算、进度与保证范围

必要选址及增长共享 8,000,000 次合法性检查预算；不足群系最多局部重选址 3 次，保留已满足地块。错误包含阶段、群系、面积或缺口、相关竞争群系，不能通过放宽硬规则或散点拼配额“成功”。32 方块温度容量统计是供给诊断，最终 4 方块实际所有权才决定可行性；有限搜索失败不等价于证明所有可能布局无解。

界面新增温度带、种子选址、必要生长、填充、过渡、验证阶段，并显示重试对象与原因。生长进度按实际已取得面积反馈；填充按环境处理和已分配单元反馈。发布前最多显示 99%。缓存命中直接恢复已冻结计划。

目标是软规模，受竞争或河流、地形阻断时允许停在最低与目标之间。必要地块主体保证四邻接连通；填充采用低分辨率全域生长后在实际位置再次检查硬规则。局部整理受限于预算，不承诺世界上不存在任何细长天然山谷或地形边界小片。

## 验证与图像

`neoforge/tools/DemandPlannerAudit.java` 可复跑完整大陆、侵蚀、水文、群系及存档编码流程，并输出温度带图、群系图、地形图、逐片面积与连通统计、独立的温度分类图。它使用测试结构占地；真实 Minecraft 结构适配另由 GameTest 验证，不能把该工具输出视为游戏截图或真实结构 NBT 验收。

```sh
javac -cp "$(cat /tmp/awg-test-classpath.txt)" -d /tmp/awg-audit neoforge/tools/DemandPlannerAudit.java
java -Xmx3G -Djava.awt.headless=true -cp "/tmp/awg-audit:$(cat /tmp/awg-test-classpath.txt)" \
  DemandPlannerAudit neoforge/build/reports/biomes-r16 7331 1 345705185492107788
```

最终结果记录在 `neoforge/build/reports/biomes-r16/`。图像基于当前实际规划与最终地形，温度图读取独立温度场，不用群系自带温度伪装温度带。
