# r30：自然群系衔接

## 原因

群系的最终调色板仍出现较大的锯齿，来自三条路径叠加：查询层把每个点强制位移到混合半径的外圈，5 方块尺度使相邻 quart 的方向变化过快；填充层寻找候选时使用 `x + warp`，计算距离时却使用 `x - warp`；地表规则又绕过原版 `BiomeManager` 的 fuzzy Voronoi，直接读取 `pos >> 2` 的 quart 标签。

Minecraft 的 quart 存储精度不变，但原版并不会把这份方格直接当作逐方块边界。`BiomeManager.getBiome` 会在周围 quart 角点中按种子扰动后的距离选择一个。TerraForged 的气候单元也先对坐标做连续域扭曲，再用同一坐标计算邻近单元距离。

## 修改

- 地表恢复 `BiomeManager.getBiome`，并按原版调用约定使用 `BiomeManager.obfuscateSeed`。恶地柱的空气探测例外仍保留在 fuzzy 取样之后。
- `LocalBiomeBlend` 改为两层有界连续域扭曲：96 方块以上的主弯曲占 75%，32 方块以上的边缘细节占 25%。不再把每次查询归一化到半径外圈；二维位移的欧氏距离仍不超过 `blend_radius`。
- `FillerLayout` 使用同一个 `x + warp / z + warp` 点完成候选定位和 Voronoi 距离计算，避免合法候选在 16 方块规划网格边缘被漏掉。
- 内部实现修订更新为 `natural-biome-joins-r30`，旧 READY 缓存会重新规划；已有区块不会自动改写。

出生核心、结构群系保护、最低面积保护和温湿度／地形硬准入没有放宽。海洋、河流与湖泊覆盖也不参与本次陆地边界扭曲。

## 验证

- 151 项单元测试全部通过，包含群系边界、碎片数量、硬地形限制、存档往返和确定性回归。
- 新增的连续性断言逐扫描线检查边界，要求相邻方块的边界位置不能发生大跳齿，同时保留可复现的自然弯曲；半径上界、内部不变和非法候选拒绝继续验证。
- `test build -Pmod_version=0.1.0-r30 --offline` 成功，产物为 `neoforge/build/libs/adventureworldgen-0.1.0-r30.jar`。
- Minecraft GameTest 启动尝试被主机的 inotify 实例上限阻断；沙箱内外重试均在 NeoForge 配置监视器初始化处退出，测试世界尚未加载，因此本轮不把它记为通过。
