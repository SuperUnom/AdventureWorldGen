# AdventureWorldGen v1 实现状态与验收报告

日期：2026-09-07；Minecraft 1.21.1；NeoForge 21.1.249；Java 21；公开算法/格式：`planner-v2` / `plan-v2`；水文：`ftf-hydrology-adapted-v1`。

当前 r6 修复及本轮证据见[地形修复说明](变更记录/地形修复-r6.md)。以下性能与服务器记录保留为历史证据，不能直接代表 r6。

## 已实现范围

- 严格 profile 解析、规范 JSON、注册表与适配能力预检、稳定 ID/随机键/排序和完整常量 profile。
- 周期径向海岸、误差受控折线、精确点内外/最近线段、岸带、等弧长样本；世界对齐区域、四模板、邻区模板混合和连续噪声。
- 8 条主河、最多三级支流、交叉拒绝、双层弯曲、河谷/河床、湖、湿地、单调水面与 64 方块河口衔接；规划期确定性侵蚀增量场。
- 完整 16 格有向成本图、最多 8 格边采样、边界补样、双向缓存、对角绕角检查、Dijkstra、16 个邻点接入、海岸中位数共同等级与局部 8 格细化。
- 稳定需求展开、4 格不规则闭合地块、承载地块、数量/间距/占地/保护冲突、位置回退、可选实例事务回滚和独立终检。
- profile-only 编解码器、普通世界预设覆盖、异步规划硬屏障、原子计划发布、真实出生、自定义地形/表层、原版洞穴/矿物/装饰复用，以及全部受控结构原生起点抑制和冻结起点注入。

## 自动化证据

- JUnit：37 项，通过；覆盖严格配置、负坐标、稳定哈希、海岸、区域、FTF 固定参数向量、河口/汇流、侵蚀、坡度费用、紧凑双向缓存、固定容量 Dijkstra、联合规划、结构内出生、持久化损坏/重试、plan-v2 往返及 10 次/三种访问顺序确定性。
- GameTestServer：3 项全部通过（30.44 秒）；覆盖安全出生、四种原版群系、冻结沙漠神殿、外部群系资源/表层/植被，以及跨区块 waystation 的旋转、战利品 NBT 和幂等键。
- 测试伴生专用服务器：半径 1536 首次规划 15.796 秒；重启 READY 加载后服务器 0.810 秒完成。225 个 waystation 周边强制区块中只发现一个 `testcompanion:waystation` 起点，起点包含两个 `minecraft:tedp` 部件，跨区块引用和沙漠神殿战利品均已落盘。
  > 历史记录：该批使用原版 `minecraft:tedp` 部件与适配器逐区块提交键；两者都已被重构替换（自定义部件类型 + 原版 `StructureStart` 流水线），当前证据见下方《P4 结构适配验收》。

## 标准性能与实机结果

固定生产验收种子为 `424242424242`，使用内置半径 6000 profile，未缩小任何作者约束，也未用墙钟提前终止：

| 项目 | 结果 |
|---|---:|
| 首次完整规划 | 154.806 秒 |
| 规划期连续内存采样 | 250 ms 间隔，共 568 个样本 |
| 保守内存峰值 | 768.12 MiB（堆已用 + Metaspace + 类空间） |
| 计划 SHA-256 | `87acbae2a783e2dad23b0bfaaa6597870b23b4e9401ed5b296b74c4c9093dcb0` |
| 成本图 | 558,009 节点；1,344,813 条唯一相邻边 |
| 水文/侵蚀 | 43 条河道；2,085 个河点；2,449,225 个侵蚀样本；45,981,810 次水滴操作 |
| READY 重启 | 1.405 秒；未重新规划；计划 SHA-256 不变 |

实际普通世界由内置 `minecraft:normal` 覆盖自动启用，出生点为 `(0.5,85,0.5)`。原版 `locate biome` 在同一不可变计划中找到 plains `(0,0)`、forest `(-64,192)`、desert `(128,-96)`、snowy_plains `(0,128)`。强制生成计划神殿周围四个区块后，区域文件只含一个有效 `minecraft:tedp` 根部件，跨区块引用与 4 个沙漠神殿战利品表均已落盘；计划外原生候选以 `INVALID` 起点被抑制。

对 1,625 个实际落盘主世界区块的方块 palette 扫描发现 `cave_air`、coal/iron/copper ore、oak log/leaves、grass 与 dandelion，验证洞穴、矿物和群系装饰流程均在自定义地形上运行。客户端在真实 OpenGL 4.6 / AMD RX 7900 XT 环境完成生产模组资源重载并进入主菜单；`runData` 也仅加载主模组并成功完成。

构建命令：

```sh
cd neoforge
./gradlew clean build
./gradlew runGameTestServer
./gradlew runData
./gradlew runClient
```

生产产物仅包含 main source set；`testcompanion` 只参与开发验收。项目本体保持 All Rights Reserved，发行 JAR 的 `META-INF/NOTICE` 包含 FreeTerraForged MIT 声明与固定提交链接。
