# AdventureWorldGen

面向整合包作者的冒险世界编排框架：在一块有限大陆上，按照共同的冒险等级与到达成本，联合安排现有模组的生物群系和结构。

可游玩 v1 已实现于 [NeoForge 工程](neoforge/README.md)：新建普通主世界自动使用 `adventureworldgen:default`，首次启动先生成并原子发布不可变 `plan-v2`，随后按计划执行有限大陆、区域地形、河湖湿地、侵蚀、群系和受控结构。水文实现为 `ftf-hydrology-adapted-v2`，固定参考 FreeTerraForged 提交 `43fd42a4d31da5ba36f5ab4d8e4d76d69688e86a`；它是适配式移植，不声称与上游逐点一致。

最新实现：[r33 分层海底与默认地形多样性](docs/分层海底与默认地形多样性-r33.md)。默认大陆最大包络半径为 3000，海底采用分层陆架与连续起伏，深层保留原版海洋洞穴；此前版本说明保留在 `docs/`。

性能更新：[r24 首次规划优化](docs/规划性能优化-r24.md)，减少海岸、区域地形与成本图的重复查询，并优化百万格群系规划的坐标集合；保留现有地形和 READY 计划兼容性。

群系规划更新：[稀有地形优先与温度贪心生长](docs/群系预规划与温度优先.md)，统一预留结构附带群系的模板容量，按可用地形面积从少到多播种，并缓存冻结场查询。r26 进一步修复种子 7993 的重复连通空间搜索，真实游戏规划与 READY 重载回归已通过。

## 从哪里开始

地形与群系修复：[r31 低地、陡海岸与温度带边界](docs/低地陡海岸与温度带边界-r31.md)，降低平坦低地、缩短海床下降距离、移除河流沙滩，并让河流不再充当群系边界。

群系衔接修复：[r30 自然群系衔接](docs/自然群系衔接-r30.md)，恢复原版地表 fuzzy Voronoi 采样，并以 TerraForged 式连续域扭曲替代逐点满半径扰动，压低群系边界的大锯齿。

面积回退修复：[r29 多区域与面积放宽](docs/多区域与面积放宽-r29.md)，搜索不足时允许多个合法区域合计，仍不够则保留实际面积，温湿度和地形限制继续生效。

温度约束修复：[r28 温度硬约束与填充配置](docs/温度硬约束与填充配置-r28.md)，温度类型统一限制播种、扩张、填充和边界混合；默认填充配置补齐气候与地形覆盖。

温度更新：[r27 自然温度场接入](docs/自然温度场接入-r27.md)，采用已确认的第七版参数、固定四档阈值与山地降温。湿度算法保持原有实现。本轮仅完成编译和三项温度定向验证，游戏效果由用户测试。

普通陆地使用原版地表规则；地形高度、河湖水位和群系位置仍由规划器决定。自定义地表仅处理实际浸水的河床、湖床等特殊位置，接入约定见[数据包与适配器开发](docs/数据包与适配器开发.md)。

## 文档使用与维护

每类事实在一个位置完整定义：产品语义在设计原则，作者字段在配置说明，求解步骤在算法文档，数值与表示在内部契约，落地与持久化在运行时契约，完成证据在验收指南。其他页面保留必要摘要并链接原定义，避免复制整套规则。

实施时先确定任务涉及的定义，再核对代码现状；发现定义互相冲突，应明确指出冲突及影响，不能根据出现次数、文件顺序或外部参考自行覆盖。候选方法不因写入实施建议而成为已确认设计。

修改规则时更新其定义和受影响的引用、验收项；修改内部数值遵守 profile 版本约定。JSON 示例中的 `example:*` 是虚构 ID，示例不代表可运行配置。`生成流程候选.md` 保留原路径，是否采用以正文标注为准。

首次规划的最新性能修改及未达 10 秒目标的阶段见 [r25 性能报告](docs/规划性能优化-r25.md)。
